# FE-01 设计稿 · 工单审计时间线 + Agent 在线/失联看板（ops.html）

> **设计**：XiaomiMiMo（前端）｜ **日期**：2026-10-07 ｜ **状态**：待老板拍板
> **配套**：`前端任务书_01_审计时间线与Agent在线看板_20261007.md`（数据契约）、前后端协作书 v1.1
> **约束**：零构建纯静态；沿用现有页面视觉语言；只读页，不含任何写操作。

## 1. 页面定位

新建 `agent_community/frontend/ops.html`，访问地址 `http://127.0.0.1:18920/ops.html`（StaticFiles 挂载，零后端改动）。

- **是什么**：只读运维看板。左侧 = 工单状态迁移时间线（谁、何时、把哪张工单从什么状态推进到什么状态）；右侧 = Agent 在线/失联看板。
- **不是什么**：不是完整历史台账（审计 ring buffer 上限 500 条）；不做任何回收/删除/重置等写操作。
- **不动现有文件**：`index.html` / `workshop.html` / `register.html` / `remote-modal.*` 全部不碰；本轮也不在现有页面加入口链接（如需加，另行申请拍板）。

## 2. 视觉方向

**风格锚点**：直接继承现有大厅页的「暗色工作台」语言——不是重新设计一套，而是让 ops 页看起来像这个产品天生的第三块面板。

- **色板**：完全复用 `index.html` `:root` 变量（背景 `#121316` 三级灰、赤陶 accent `#d97757`、语义色 green/yellow/red/blue/cyan/purple 各带 soft 半透明底）。ops.html 内联同一份变量定义，不引外部 CSS 文件（remote-modal.css 依赖这些变量，直接 `<link>` 复用其弹窗样式类）。
- **字体**：与现有一致 —— 系统无衬线（Segoe UI / Noto Sans SC / 微软雅黑）+ `--font-mono`（JetBrains Mono / Cascadia Code）用于 id、epoch、原始 detail。
- **密度**：信息密度中等偏高（运维页），条目行高紧凑但留呼吸缝：卡片圆角 10px、内边距 12–14px、条目间距 8px。
- **签名元素**：**状态迁移「双胶囊箭头」** —— `从状态胶囊 →(箭头) 到状态胶囊`，是时间线每条记录的核心视觉；终态（done/dropped/removed）的到端胶囊带实心小徽记。这让"迁移"一眼可读，而不是一串文字。

### 区块 × 数据源 × 三态

| 区块 | 端点 | 加载态 | 空态 | 错误态 |
|---|---|---|---|---|
| topbar 健康徽标 | `GET /api/status` | 徽标"检测中…"（灰） | 不适用 | 徽标变红"后端未连接"；若整页所有端点都失败，主区顶部出红色横幅：**"后端未启动，请先运行 `python -m agent_community.platform.server --port 18920`"** |
| 时间线列表 | `GET /api/audit?event=task.transition&limit=&actor=&target=` | 骨架条目（3–4 条灰色脉冲占位） | "还没有工单状态迁移记录。工单推进/完成时会自动出现在这里。" | 面板内联红条，含后端返回的中文说明（兼容 `{"error":…}` 与 `{"detail":…}` 两套 404 形状），保留上次成功数据并标注"数据可能过期" |

## 4. 左栏：审计时间线

### 4.1 筛选行

- `actor` 文本框（占位"按操作者过滤"）、`target` 文本框（占位"工单号（8位hex）"）——直接映射后端已支持的 `?actor=&target=`，**400ms 防抖**后重拉。
- 条数下拉：50 / 100（默认）/ 200 / 500 —— 对应 `limit`（服务端夹紧 1–500）。
- `event` 固定为 `task.transition`（本页只做状态迁移时间线，不出现在 UI 上）。
- 清空按钮 + "无匹配记录"与"还没有记录"两种空态文案严格区分。

### 4.2 单条记录（时间线条目）

垂直轨道 + 圆点节点，自上而下（后端已按时间倒序，最新在前）：

```
●─┬ 3 分钟前 · 16:18:35            [👤 user]  [工单名: 前端造数据-临时]  47???????? ⧉
  │  created ──▶ dropped   [丢弃 drop]
  │  备注：removed
  ▼
```

- **第 1 行**：相对时间（"刚刚 / 30 秒前 / 5 分钟前 / 3 小时前 / 2 天前"），悬停显示绝对时间（`ts` 原文）；actor 胶囊（`user` 灰、`system` 蓝、其他 id 用 mono 字体的中性胶囊）；工单胶囊 = 工作间 `name`（tooltip 显 id，点击**新标签打开** `/workshop.html?ws_id=<id>`；查不到名字降级显示原 id；名字本身含历史损坏字符 `?` 时原样显示并加 tooltip 说明）。
- **第 2 行（核心）**：`from 胶囊 → to 胶囊` + action 徽章。胶囊颜色按 §5 状态色板；箭头用 → 字符。
- **第 3 行**：`note` 非空时显示（`备注：…`），空则省略。
- **解析失败**：整行降级为灰色 mono 原文 `detail` + 小标签「未解析」，不隐藏、不崩溃。
- **节点圆点颜色** = `to` 状态色，让整条轨道的颜色节奏反映"工单最终去向"。

### 4.3 点击行为

- **单击条目** → 展开原始详情区（等高动画）：`detail` 原文、`event`、`target` 原文、ISO 时间、正则解析出的 ev/from/to/action/note 五个字段。**不跳转、不发请求**。
- 再点收起。默认全部收起。
- 工单胶囊上的 ↗ 图标是唯一跳转出口（读操作范畴内的页面导航）。

### 4.4 action 徽章（配色即语义）

| action | 徽章样式 | 文案 |
|---|---|---|
| `escalate_l2` | **红底实心 + 左侧闪烁圆点**，最醒目 | 需人工介入 |
| `escalate_l1` | 黄底 | 组长裁决 |
| `auto_retry` | 蓝底 | 自动重试 |
| `pause` | 黄底 | 暂停 |
| `resume` | 青底 | 恢复 |
| `done` | 绿底 | 完成 |
| `drop` | 红底 | 丢弃 |
| `noop` | 灰底 | 直接置位 |

> `escalate_l2` 是"系统在喊人"，必须在整屏里第一眼被看到；`noop` 是系统常规推进，最安静。

## 6. 右栏：Agent 在线/失联看板

### 6.1 汇总 chips 行

`● 在线 n`（绿）｜ `▲ 失联 m`（红/灰，m=0 时灰）｜ `共 N`（中性）｜ `阈值 ×2.0`（tooltip：失联阈值 = 上报周期 × timeout_scale）。

### 6.2 在线卡片（`heartbeat.online`，以 agent_id 为主键）

```
● 示例Harness-A              [忙碌]
  agent-fresh · 30s 上报 · 上次 12 秒前
  "正在跑子任务"
```

- 状态点/标签三色：`alive`=绿（呼吸动画）、`idle`=黄、`busy`=蓝（呼吸动画）；中文标签 在线/空闲/忙碌。
- 标题行：`harness_name || agent_id`（名称空串则用 agent_id）；第二行 mono：`agent_id` + `interval` 秒 + 相对 `last_seen`（悬停绝对时间 `new Date(last_seen*1000)`）。
- `note` 非空显示为引号斜体，空则省略。

### 6.3 失联卡片（`heartbeat.stale`）

同在线卡片结构，叠加：**红系 2px 左边条 + 「失联」红徽章**；额外一行必显：`last_ago`（"已 200 秒未上报"）与 `threshold`（"阈值 60 秒"），hover 在状态点上显示 `since` 首次登记绝对时间。失联区永远排在在线区之下、以标题「⚠ 失联 (m)」分组；m=0 时不渲染分组标题只显示空态行。

### 6.4 空态（常态）

两个列表当前线上都是空的——空态是**默认要好看的状态**，不是异常兜底：居中图标（时钟/雷达字符画或 SVG 线图标）+ 主句 + 副句（副句解释"怎么会这里有数据"）。任何路径不出现 `undefined` / `NaN` / 白屏。

## 7. 刷新策略与全局行为

- **轮询 12 秒**（`setInterval`），一次周期并行拉 4 个端点（audit / status / heartbeat / stale，workshops 仅首拉 + 每 5 分钟刷新一次）。
- `visibilitychange`：标签页隐藏时暂停计时器，**恢复可见立即拉一次**再重启计时（任务书 §6.1）。
- 手动 ⟳ 按钮 + topbar 显示"上次刷新 HH:MM:SS"；请求进行中按钮转圈防连点。
- 单端点失败不影响其他端点渲染；失败计时器照常走（下轮自愈）。
- **不做 WebSocket**（`/ws` 与本页无关）；**不轮询 `/api/audit` 超过 15s**（后端写审计 5.75ms/条，12s 满足）。
- 时间处理铁律：`ts` 是**本地 ISO 无时区串** → `new Date("2026-10-07T16:18:35")` 直接用，**不补 `Z`/`+08:00`**；心跳 `last_seen/since` 是 epoch 秒 → `new Date(x*1000)`。

## 8. 窄窗口取舍（1920 基准；1280×720 与 1024 宽必不破版）

| 断点 | 布局 |
|---|---|
| ≥1400 | 左 `1fr` + 右 `360px` 双栏，各自内部滚动 |
| 1100–1399 | 右栏 `320px`，条目内工单胶囊允许省略号截断（tooltip 保底） |
| <1100（含 1024） | **单列堆叠**：时间线在上（最小高 50vh、内部滚动），心跳看板在下（内部滚动）；筛选行换行成两行；**不横向滚动、不裁切徽章** |

优先级（真挤了先砍）：① 备注行 → ② 卡片内的 interval/上报周期行 → ③ statusbar 文案缩短 → ④ 时间线只留相对时间（绝对时间仅 hover）。**永不砍**：双胶囊箭头、escalate_l2 徽章、失联红条。

## 9. 验收自查（对应任务书 §7 八条）

1. `/ops.html` 可达、Console 无红错 —— 交付时自测截图。
2. detail 解析：内置任务书 §4 三条样本做 `window.__opsTest` 暴露的自测函数（Console 可跑）；畸形样本（如 `garbage line`）走降级渲染。
3. 空态：现网即空态，直接目检。
4. 工单名映射：现网 workshops 有 20 条、审计 target `dd4b6d75` 需查映射；查不到降级 id。
5. 失联看板：按任务书 §8 用 Python 造心跳 → 等 60s+ → 核对 `last_ago`/`threshold`。
6. 1920 / 1280×720 / 1024 三档目检。
7. 停后端 → 刷新 → 中文错误横幅。
8. 只读：页面无任何 POST/DELETE 调用（代码级可查：全部请求为 GET）。
