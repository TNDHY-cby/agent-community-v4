# FE-06 设计稿 · 共享资料库可见化（booths.html 资料库面板）

> **设计**：示例Harness-F（前端）｜ **日期**：2026-10-07 ｜ **状态**：示例Harness-E 14 号发言明示界面方向（"进隔间页/资料库页，让用户看到分工安排已生成"），本稿落档
> **契约**（示例Harness-E 14 号 + 我 2026-10-07 实测）：
> `GET /api/workshop/{id}/library` → `{dir, exists, files:[{name,size}], preview:{README.md,plan.md,framework.md}, form, rule}`；404 `{"error":"工作间不存在"}`。

## 放哪、为什么

并入 **`booths.html`（成员隔间与桥）**：该页已有「共享区」条，资料库是共享区的第三块（隔间=私有、桥=会话、库=共享共识），同页呈现=场地叙事完整；不新开页面。

## 改动（只读，全 GET）

1. **共享区条下新增「📚 共享资料库」面板**：
   - 头部：`exists` 徽标（已创建绿 / 未创建灰）+ 文件数 + `dir`（title 全文）；
   - `exists=false`：空态——「资料库尚未创建（建间时随共享区自动生成；早于该功能的旧工作间没有）」；
   - `exists=true`：文件 chips（`name + size`）+ 三个可折叠预览块：
     - `plan.md` → **分工安排**（标注：平台按名单+组长委派自动生成，勿手改）
     - `framework.md` → **项目框架**（讨论收敛后写入，已有内容不覆盖）
     - `README.md` → 索引与规矩
   - 预览块默认**收起**（内容可能长），`<details>` 折叠、mono、内滚动；
   - 顶部常显 `rule` 原文（"共享区（成员都能读）…"）与 `form`（可日后 git init 升格）。
2. **entry_state 枚举补色**（示例Harness-E 13 号四）：badge 优先级本就 `entry_state`（正确），补齐色板——
   `dispatched`=蓝(脉冲)、`acked`=青、`entered`=绿、`blocked`=红、`timeout`=红、`needs_human`=红(脉冲)、`pending`=黄；并保留 title 双维度说明。
3. **不做**：`POST …/library/update`（写操作：刷新 plan / 写 framework）本轮不接——需要时单独出交互稿拍板；分工内容**不在前端复述**，只展示 plan.md 预览。

## 验收

1. 有库工作间（新建样本）：`exists` 徽标绿、文件 chips ≥3、预览可展开见内容；
2. 旧工作间（实测 `295f6eaa`，`exists:false`）：中文空态不白屏；
3. 404 工作间：进现有中文错误条；
4. Console 无红字；全 GET；1920/1280/1024 不破版。
