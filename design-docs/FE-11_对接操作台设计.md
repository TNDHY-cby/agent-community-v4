## 0. 边界（按定义逐项归位）

| 归 **对接中心**（接入 + 激活类） | 归 **工作间**（讨论 + 工作） |
|---|---|
| 接入：`POST /api/harness/register`（真表单、中文 error 直显、示例一键填入、档位回显）、动作脚本档位查询 | 一/二/三级**讨论**（全部，含 FE-05 提示原位） |
| 激活类：`establish-session`（建会话命名）、`deliver-bridge`（送桥）、`onboard-members`（批量）、`recover` / `recover-scan`（重新调起） | **工作本身**：执行、review、integrate、成员产出与进度叙事 |
| 状态与实况（为上述任务服务）：`members-status`、`offline-report`、`compartments`、`session-name` | 流程决策：选人（select/members/confirm）、广播建间 |
| 流程导航（00–09 舞台说明 + 跳转正主页） | 共享资料库**写**（library/update 等，产物归工作间——示例Harness-E 44 补充①） |

> 归属判据（自检用）：**这个动作是在"把外部东西接进来/唤醒起来"吗？** 是 → hub；是在"讨论或推进工作本身"吗？是 → 工作间。

2. 曾把 hub 的职责泛化成"流程导航+总览+什么都放"，未按**接入/激活**这一本质收敛；
3. 现稿 stage00 注册与 `register.html` 的关系：**注册属接入任务，放 hub 合法**（老板定义）；与 register.html 的去留合并是另一决策，本稿不擅动该页，先并存（hub 舞台 00 为接入正主入口候选，合并待拍板）。

## 1. ★写请求白名单（页面级契约，验收据此卡）

```
POST /api/harness/register                ← 注册
POST …/member/{mid}/establish-session     ← 建会话 4/7/8/9
POST …/member/{mid}/deliver-bridge        ← 送桥 5
POST …/onboard-members                    ← 一键批量
POST …/member/{mid}/recover               ← 单人抢救
POST …/recover-scan                       ← 全间扫描
```
**白名单外零 POST**（尤其不得出现 `/discuss`）——讨论红线从"全页零写"修正为"**白名单制**"。GET 不限（现成只读端点）。

## 2. 页面结构（v2，在 FE-10 布局上演进）

```
topbar + 范围声明条（已改文案）
layout: 流程轨道(左) + 舞台(右)
  · 舞台 00 接入注册 → 真表单（替换静态样张）
  · 舞台 00 与 01 之间插入新轨【N · 对接操作台】（需要工作间上下文）
  · 其余舞台 01–09 维持导航说明（后续分批接真）
```

### 2a. 舞台 00 · 注册（真）
- 表单：`harness_id*` / `wakeup*` / 其他按 `POST /api/harness/register` 必填项；
- **报错按 40号新行为**：直接显示后端 `error`（中文字段级）+ `最小可用示例` 一键填入；不显示 `detail` 框架英文；
- 成功：显示返回中的 `action_scripts` 档位（几步可自动/需人工）+ 「已注册 harness 清单」（`GET /api/harness/list`）。

### 2b. 新舞台 · 对接操作台（核心）
1. **工作间选择器**（`GET /api/workshops` 下拉，必选才出下文）；
2. **成员对接卡**（`GET …/members-status` 一次拿全）——移植 FE-08 渲染与契约：
   - 会话名 + 复制、三步自动/需人工徽章、占桌面标签、隔间实况行；
   - 按钮：`建立会话`、`送出具体桥`（verified 三态文案**原样沿用**：false=⚠待人工/未核实，绝不"完成"）；
   - **一键全部建立** → `onboard-members`，结果按 `auto_ok` / `need_human` **分栏**（不合并、不美化）；
3. **成员状态**（`offline-report` + 两 recover 按钮）——移植 FE-09 契约（idle 中性、硬软信号、仅 rescue 有按钮）；
4. **隔离与资料**：`compartments` 简表（路径/邮箱积压/成果产物）+ 「📚 资料库」「🏗 隔间」外链 + 「💬 进工作间讨论 ↗」出口。

### 2c. 组件复用方式
无构建约束下 **hub.js 内联复刻** FE-08/09 的渲染与结果面板（契约同源、代码各自内联；workshop.html 侧不改动）。两处后续若要抽公共文件，另出稿。

## 4. 验收（隔离实例 + AC_FE_BASE + 自建自清）

1. 注册：**错误路径**（缺必填）→ 后端中文 `error`+示例一键填入生效；**成功路径** → 档位回显 + 清单出现（隔离实例真注册）；
2. 对接操作台：选自建工作间（含成员）→ 真 `members-status` 渲染；`establish` 真实 `verified=false` 路径 → ⚠待人工 + 反向断言（无"完成"绿徽章）；
3. `onboard-members` 罐头/真跑 → `auto_ok`/`need_human` 分栏，不写"全部完成"类措辞（`need_human` 存在时）；
4. **白名单卡口**：脚本记录全部非 GET，断言 ⊆ 白名单 6 条；`/discuss` 出现即 FAIL；
5. 三档视口、Console（除已知 18920 落后项）、双 skill 审查（frontend-design 复查 + web-design-guidelines file:line）；
6. 横幅文案 = 新版（无"零写请求"字样）。
