## 2. 自检四态灯（文案取 V39 §3②，原因/建议显示后端 `advice` 原文）

| state | 灯 | 标题（人话） |
|---|---|---|
| `ok` | 🟢 绿 | 通了（桥取走了 + 你的 agent 回话了） |
| `no_reply` | 🟡 黄 | 桥取走了，但你的 agent 没回话 ⇒ 多半是没配「叫醒命令」 |
| `not_picked` | 🔴 红 | 消息还躺在邮箱里 ⇒ 桥没在运行 |
| `not_set_up` | ⚪ 灰 | 还没架桥（没有邮箱） |
| 请求失败/`error` | 🔴 | 后端原文 |

下方固定给「怎么办」= 后端 `advice` 原文；脚注说明自检**会真发一条测试消息**（不改状态、留审计）。
