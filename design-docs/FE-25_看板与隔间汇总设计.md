# FE-25 看板与隔间汇总设计

来源：107号看板汇总建议。范围：ops.html、booths.html及独立验收脚本。

沿用现有深色运维面板和 count-pill，在工作间三问标题区、成员隔间卡标题区各加两项：孤儿 N 人、未送达 N 条。只展示汇总数字；headline 放 title，详情继续在工作间处理。

工作间选定后并行 GET /api/workshop/{id}/orphans 与 /delivery-status。人数取 orphan_count，条数取 total_pending，不把 stuck_count 当作未送达总数。0 态采用中性色，有值采用现有黄色。未选工作间显示 —；接口失败显示“加载失败”，不沿用其他工作间的旧值，不猜零。

验收：自建自清隔离工作间；两页各验真实0态、打桩非零态、接口失败态及切换空选择；页面只读GET。真实浏览器截图检查布局，并复跑FE18、FE19。
