## 5. 高频坑（我今天全踩过，一条条记下来）

### 5.1 行尾必须是 LF ★最容易栽
Windows 上用 Python `Path.write_text()` 默认写出 **CRLF**，守卫 `test_frontend_files_use_lf_endings` 会红。
```python
p.write_text(s, encoding="utf-8")            # ❌ CRLF
p.write_bytes(s.encode("utf-8").replace(b"\r\n", b"\n"))   # ✅
```
改完任何 html/css 都要确认一次：`raw.count(b"\r\n") == 0`。
**我今天在这上面红了两次。**

### 5.2 `background-image` 会被 `glass.css` 抢
`.col-center` 等容器被 `glass.css` 的 `:is(.main,.stage,…,.col-center,…)` 规则占着 `background-image`（红/蓝光斑）。
你写的同名属性若特异性不够 **不生效**（我因此连改 3 次都"看不见"）。
先查：`getComputedStyle(el).backgroundImage`，再决定是加特异性还是显式覆盖。

### 5.3 `clip-path` 会连 border 和 box-shadow 一起裁掉
想"切角"时用 `clip-path` → 面板立刻**没有边框、没有投影**，变成一块没有边界的面。
- 需要保留投影：用"与外部同色的三角盖住角"（盖法），或 `filter: drop-shadow()`（跟随 clip 形状）；
- 小元素（按钮/步骤块）才用 `clip-path`。

### 5.4 选择器写宽了会"框里套框"
`.ws-status *`（带通配）把每个子元素都刷了背景 + 边框 + 倒角 → 状态胶囊里出现"框里套框 + 残角"。
**只给容器本体，子元素只改文字色。**

### 5.5 规则会失控
`industrial.css` 是我在一天里**追加了 40+ 块**堆出来的（`㉑`~`㊶` 编号），互相覆盖、越往后越难判断哪条生效。
**接手后第一件事建议：挑一个页面，把该页面相关规则合并成一份干净的重写**（别在大文件上继续追加）。
判断某条是否生效：`getComputedStyle` + 截图取像素，**不要靠看源码猜**。

### 5.6 元素定位别猜，用探针
```js
document.elementFromPoint(x, y)   // 这个坐标到底是什么元素、它的背景/颜色
```
我今天有三次"改了但没效果"，都是因为改错了元素（比如把浅色字挂在 `.panel` 上，实际是 `summary.col-header`）。

### 5.7 服务会掉
一周掉了十几次，表现是"进程在/不在，但 18920 拒绝连接"。**截图前先探活**，别把"旧图"当新结果。
