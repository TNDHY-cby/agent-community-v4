> ⚠️ **2026-10-25 老板改口径（覆盖本文里"要截图"的部分）**：
> 「**不用截图，让用户自己去外端 agent 会话里面看**」
> ⇒ **平台不再自动截图**。证据只保留"结果卡 + 一次性口令"，
> 另加一个动作：**「打开它的会话」** —— `POST /api/docking/harness/{id}/bring-front`
> 把那个窗口抬到前台，剩下的**用户自己看**；平台不截屏、也不替用户判断它回了什么。
> 第 3 节里的 `shot*` 字段**已停用**（字段位保留、不再产出）；`shots` 两个端点只用于回看**历史**留下的图。


> **老板原话**（问"3 是不是可选"时）：
> 「**3 是必需的**，不然以后接进来也看不到外端 agent 在它的会话里面干活」
>
> 这里的 "3" ＝ 我给的第三个方案 = **证据卡 + 随机口令 + 截图**。
> 老板把"截图"从"可选"提到"必需"，理由不是"测试时要好看"，而是 ——
> **接进来之后，用户要随时能看见它到底有没有在自己的会话里干活**。

## 1. 问题（一句话）

MCP 这类协议，平台调的是**工具接口**：回复只回到平台，**不会出现在那个 agent 自己的聊天窗口里**。
所以"它到底有没有在干活"这件事，平台必须**自己留证**，而且证据要让用户**一眼看得见**，不能只有一句"通了"。

## 2. 三条证据（从"接口通"到"我看得见"）

| 层 | 证据 | 解决的问题 | 状态 |
|---|---|---|---|
| ① 结果卡 | 发了什么 / 谁接的 / 回了什么 / 用时多久 / 上次什么时候测的 | "到底通没通" | 已有（`test-now` + `overview.last_test`） |
| ② **随机口令** | 每次测试带一个一次性口令（如 `收到-A37E42`），对方回显里**必须带回它**才 `verified:true` | "是不是假成功"（缓存/老回包/写死应答） | **本轮新增** |
| ③ **留档截图** | 测完/投递完**自动存一张**它的窗口截图进 `data/shots/<harness_id>/<时间戳>.png`，**不覆盖**，可按时间回看 | "它在自己会话里到底干没干活" | **本轮新增** |

## 3. 后端接口（前端照这个接）

```http
POST /api/docking/harness/{id}/test-now
{ "text": "请回复：收到", "visual": true }     # visual 可省；桌面类会自动留截图

→ {
    "ok": true, "kind": "mcp", "tool": "echo",
    "text_sent": "请回复：收到（口令：收到-A37E42，请原样带回）",
    "reply": "请回复：收到（口令：收到-A37E42，请原样带回）",
    "nonce": "收到-A37E42",
    "verified": true,                  # ← 只有回显带口令才为 true
    "verify_note": null,               # 未带回口令时这里是**人话解释**（不算真接住）
    "shot": {"ok": true, "name": "20261025T081500_0800.png", "width": 1600, "height": 900},
    "shot_url": "/api/docking/harness/<id>/shots/<name>",
    "shot_note": null,                 # 没截到时写清为什么（没绑定窗口 / 窗口已关）
    "elapsed_ms": 301, "at": "..."
  }
```

```http
GET /api/docking/harness/{id}/shots            → 最近截图清单（时间倒序，含 url）
GET /api/docking/harness/{id}/shots/{name}     → 取那张 PNG（挡路径穿越）
```

- **投递/试投/视觉激活**（`visual-run`）跑完也会**自动留一张**（成功失败都留，失败那张更能说明卡在哪）；
- 桌面类（`clipboard`/`file_poll`/`pending_poll`）在 `test-now` 里也会尝试留一张，取不到就写 `shot_note`。

## 4. 真机结果（本机实测）

| 对象 | 结果 |
|---|---|
| MCP harness（`cherrystudio-win11-general`） | `tool=echo`、`nonce=收到-A37E42`、回显含口令 ⇒ **verified=true** |
| 桌面类（`trae-win-desktop-dev`） | 如实回"没有可调接口"，截图 `shot_note="拿不到窗口 DC（窗口可能已关闭）"`（**窗口关着就明说，不假装**） |

## 5. 两条边界（别越界解释）

1. **口令只能证明"这条消息它接住了"**，不能证明"它理解了"；理解与否仍要靠①结果卡 + 人看截图；
2. **截图是"当时的样子"**，不是录像；要连续看它在干活 → 用监控室（同一条 `data/shots` 之外的实时流），不是靠这里刷图。
