# V103 · 「它回的话」：回显不是回复 —— 谁在说话必须分得清

> ⚠️ **2026-10-25 老板拍板：V103 这条线（让对方在自己会话里回话／平台核它回的话）已停产**。
> 现行主线是 **`V105` MCP 真正落地**（平台当 MCP 服务端，它来调我们的工具）。
> 本文件保留：里面的**判据**（读对方自己的库、回显不是回复）在诊断时仍然有效，但**不作验收依据**。

> 起因：老板 2026-10-25 在 Cherry Studio 里指着会话说「**我要看回复**」。
> 现状（当日真机核实）：平台「测一次」发一句话进去，对方返回体里有个 `reply` 字段 ——
> **那就是我们发出去那句的原样回显**，会话里的模型根本没有开口。
> 若把它当"它的回复"显示，用户会以为对方答过了（又一次"看起来成功"）。
> **状态**：后端已落地（2026-10-25，守卫 `tests/test_agent_reply.py`）；界面显示见通道 `D后端-35`。
> **谁写**：DSH（后端）

## 1. 事实（当天用**它自己的库**读出来的，不是我猜的）

```
库：<对方应用自己的>cherrystudio.sqlite   （只读副本）
最后几条（全部是我们发进去的，没有一条是它自己说的话）：
  16:32:31 | 会话 8d3b2a97 | 请回复：收到（口令：收到-8C4DCE，请原样带回）
  13:56:49 | 会话 8d3b2a97 | 请回复：收到（口令：收到-8EF73D，请原样带回）
  …
```

- 插件的 `session_post` 做的是：**往它库里插一条消息**，返回
  `{ok, in_session, session_id, session_title, message_id, text, reply}`；
  其中 `text` 与 `reply` **都等于我们发的那句**；
- 插入动作**不会触发**那个会话里的模型 —— 所以"它的回复"从来就不存在（不是"延迟出现"，是"不会出现"）。

## 2. 三条口径（写进契约）

| # | 口径 | 不许 |
|---|---|---|
| ① | `reply` / `text` 是**回显**，不是回复 | 不许当"它答了"显示 |
| ② | 只有**我们那条之后新出现的、不是我们的话**才算它的回复 | 不许把我们自己的话算成对方说的 |
| ③ | 读回来**没有**它的消息时，界面必须写"**它没回话**"＋原因 | 不许留空、不许假装成功 |

## 3. 契约（`POST …/docking/harness/{id}/test-now` 增补，既有字段语义不变）

| 字段 | 含义 |
|---|---|
| `agent_reply` | `{ok, items:[{text, role, id, at_ms}], note, skipped_ours, unknown_time}`；`items` 只放**它说的话**（最多 3 条） |
| `agent_reply_note` | 一句话结论：`它回了 N 条：…` / `它**没回话**：…（应用不会因为我们写库就自己生成回复）` / `读回的内容里没找到任何消息` |
| `wait_ms`（请求体） | 发完**等多久再读**（毫秒，默认 1200；传 0＝不等，上限 15000）。等待是为了给"它刚生成的那条"落库的时间 |

判定细节（`routers/docking.py::_extract_agent_reply`，一处真相）：
- 带这次口令的消息 ⇒ **就是我们那句**，跳过（并计入 `skipped_ours`）；
- 时间早于我们这条 ⇒ 旧消息，不算；时间认不出来 ⇒ 只按内容判（`unknown_time` 会写出来）；
- 明确标成 `user` / `human` ⇒ 那是人打的字，不算它的回复；
- 正文认三种形状：`text` / `content` / `parts:[{type:"text",text:…}]`（它库里就是 `parts` 这种）。

## 4. 想真的拿到回复，只有两条路（如实说，不硬撑）

| 路 | 谁做 | 现状 |
|---|---|---|
| ① 让**它的插件**在 `session_post` 时顺便触发一次生成，并把生成结果写进会话、回给平台 | 对方应用 | **平台给要求**（`…/session-post-guide` 的话术里已有"说出你写的表/字段"，可补一句"要能触发一次生成"）；现在它做不到 |
| ② **打进它的输入框**（视觉投递 `POST …/deliver`），让它自己的模型跑起来，平台再截图/读回 | 平台（现成能力） | 需要**先把它绑到一个窗口**（界面上一次）：现在这个 harness 没有绑定 ⇒ `delivery` 如实回"认不出它是哪个窗口" |

## 5. 判据

- `tests/test_agent_reply.py`（6 条）：回显不算回复 / 之后的新消息算 / 旧消息不算 / `user` 角色不算 /
  `parts` 与纯文本都认 / 读回空要说话；
- 真机一次（2026-10-25，真库 + 真插件）：
  `truth_verified=true`（库里有我们那句）、`agent_reply.items=[]`、
  `agent_reply_note="它**没回话**：会话里只多出我们这句…"` —— 这条链现在**会如实说它没回**。
