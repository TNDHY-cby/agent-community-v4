## 1. 适配器接口（三档统一形状）

```python
class Adapter(Protocol):
    kind: str            # "a_protocol" | "b_bridge" | "c_visual"

    def pull(self, workshop: dict) -> list[Raw]:      # 取原始报文（A: HTTP 已入；B: 扫 _inbox；C: 前端提交）
        ...
    def ack(self, raw: Raw, result: ParseResult) -> None:   # 回执已处理（B: 移动/改名；A: HTTP 已回；C: 界面提示）
        ...
    def wakeup(self, member: dict, payload: dict) -> WakeResult:
        ...   # {"result": "ok|queued|manual|failed", "detail": "...", "at": "..."}
    def revoke(self, member: dict) -> None:
        ...   # A: 吊销 token；B: 删除待取文件；C: 无
```

规则：
1. **一行业务代码都不许知道"档"**：`intake` 之后只有 `Receipt`；
2. 适配器**只做搬运与鉴权**，不解析语义（解析器唯一，`V110`）；
3. 新增一种 harness = 加一个适配器 + 一条 `template.kind` 映射，**不动核心**。

## 2. 三档对照（施工表）

| | A 协议型 | B 桥型 | C 视觉型 |
|---|---|---|---|
| 回执怎么来 | `POST /api/ws/{id}/intake` | 写 `_meta/_inbox/<seq>-mbr<seq>.rcpt` | 界面粘贴 |
| 凭据 | `session_token`（绑定、TTL、可 revoke） | 位置即凭据 | 无（绑上下文 + 人确认） |
| 平台怎么知道"是它" | 校验 token | 只能由本机写进该目录 | 记账 L4（`who/when`） |
| 取件 | 即时 | **轮询**（默认 2s，可配） | 用户点提交 |
| 处理完 | 直接回 200 | 文件移到 `_meta/_inbox/_done/` 并留 `.result.json` | 界面显示解析结果 |
| 失败怎么让人知道 | HTTP 4xx + `next` | 文件留在原地 + `_meta/_inbox/_fail/<seq>.err` | 界面红字 + 可"改一改再提交" |
| 典型 harness | 有工具面的 agent（MCP/ACP/HTTP） | 只能读目录的 agent | 只有 GUI 的（网页版/桌面） |

**幂等**：三档都按 `(workshop, member, seq)` + 内容哈希去重（`V110` §4）。

## 3. 激活（三步，缺一不算）

```
① 写任务文件  <slot_dir>/任务/T-<seq>.md          ← 正文来源：组长给（回执/文件已在）
② 追加通知    <slot_dir>/_notice.md 一行（时间 | 文件 | 版本 | 一句话）
③ 触达        A: 发请求 / B: 写唤醒标记文件 / C: 标"待唤醒"
记账：activated_at + wakeup_result(ok|queued|manual|failed) + 谁发起的
```

| 档 | 触达手段 | 成功判据 | 失败怎么说 |
|---|---|---|---|
| A | 平台调它的 wakeup（HTTP/MCP/ACP） | 收到非错误响应（L0） | `failed` + 原因（连不上/超时/401） |
| B | 写 `<slot_dir>/_wakeup.flag`（含任务号与时间） | 桥**真取走**了（文件消失或有 `.acked` 标记） | `queued` + "还没人取件（等桥轮询）" |
| C | 无技术手段 | **永不自动成功** | `manual` + "去它的窗口说一句：看下 `任务/T-003.md`"（附可复制的一句） |

**硬规则**（防"看起来成功"）：
1. `manual` **不进 `activated_at` 的"已激活"统计**（分开计数：已激活 / 待人工）；
2. `queued` 超时（默认 10 分钟无取件）⇒ 降级为 `manual` 并红字，**不许**一直挂"已排队"；
3. 一次激活**最多重试 3 次**，之后只提示人工（避免无限打扰）。

## 4. 叫不醒怎么办（H09：流程不判死，只降档）

| 情况 | 平台做什么 | 用户看到 |
|---|---|---|
| A 档连不上 | 重试 3 次 → `failed` | 红字"叫不醒（连接失败：原因）"，给一句可复制的催办话 |
| B 档没人取件 | 10 分钟后 `manual` | 红字"桥没取件（可能是桥进程没跑）"+ 怎么起桥 |
| C 档 | 直接 `manual` | "需要你到它的窗口说一句"（给可复制文本） |
| 成员 `lost` | 吊销 token、置 `lost` | "这个成员不在了"，并给出"替换成员"按钮（同 slot_dir 新 member_seq） |

## 5. 讨论区在哪个适配器里（待拍板第 7 条的两套落点）

| 选择 | 适配器要做的 | 平台要存的 |
|---|---|---|
| 平台内路由 | 消息走 `discuss` 端点（复用现有），适配器不管 | 消息 + 路由记录 |
| 外端群聊 | 适配器只需**收集链接**（C 档：用户粘链接；A/B 档：回执里带 `thread_url`） | `threads` 表（链接/标题/参与人），**不存消息** |

两套都保留位置，等你拍。

## 6. 判据（施工时真跑）

| # | 判据 | 真跑方式 |
|---|---|---|
| 1 | A 档：没 token ⇒ 401/403；有 token 且越界 ⇒ 403 | 两个工作间各签一个 token 交叉用 |
| 2 | B 档：位置即凭据 —— 在**本工作间目录之外**放 `.rcpt` ⇒ 平台不认 | 放到别的目录再复制进来 |
| 3 | B 档：处理完文件真被移走，且 `_done/` 有 `.result.json` | 真写一个桥文件 |

| 6 | `manual` 不计入"已激活"计数 | 看统计两栏分开 |
| 7 | B 档 10 分钟无取件 ⇒ 自动降 `manual` | 把超时配成 5s 验一遍 |
