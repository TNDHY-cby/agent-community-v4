## 2. 判据清单（按批）

### R：回执与 intake（P1，20 格）
| # | 判据 |
|---|---|
| R1 | 首行不是 `#回执 v1` ⇒ `R001`，且带 `fix` |

| R5 | 行数不符 ⇒ `R005`（附"你有 3 条"） |
| R6 | 同 seq 同内容重发 3 次 ⇒ 库 1 条 + 后两次 `duplicate:true` |
| R7 | 同 seq 不同内容 ⇒ `R010` |
| R8 | seq 回退 ⇒ `R006` + "下次用 13" |
| R9 | 体行里出现半角 `\|` ⇒ `R009` + 教怎么写 |
| R10 | 拒收也落盘（`receipts` 表能看到原文 + 全部 errors） |
| R11 | A 档无 token ⇒ 401；越界 token（别的成员）⇒ 403 |

| R15 | B 档失败：留在原地 + `_fail/<seq>.err` 写明原因 |
| R16 | C 档：同一文本粘两次 ⇒ `duplicate:true` |

| R18 | 回执里 `工作间` 不存在 ⇒ `R007` + 列出可用工作间 |
| R19 | `派活` 类回执只落索引，**不把正文存 DB** |
| R20 | 原始报文落 `AC_DATA_DIR/receipts/…`（换数据目录也跟着走） |
