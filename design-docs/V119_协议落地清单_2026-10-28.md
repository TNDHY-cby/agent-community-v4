## §1 "协议落地"的唯一定义（Done 的五条）

一条协议只有**五条全绿**才算落地，缺一条就写"未落地"，不许写成"支持"：

| # | 条件 | 怎么验（真判据） |
|---|---|---|
| ① | **可发现**：`GET /api/protocols` 里状态正确（`available` / `partial` / `not_implemented`），带 `layer`+`semantics` | 真请求比对，不许照抄文档 |
| ② | **有真机判据**：有工具、格数是硬的，且**在临时实例（换端口+换数据目录）上跑** | `tools/*_check.py` 退出码 0 |
| ③ | **端到端一条链**：从"外部来消息"到"平台记账 + 可查回"闭合 | 判据里必须出现"派活→回报"或"调工具→落账" |
| ④ | **失败要说话**：缺依赖/不支持时返回明确原因与下一步，不静默、不假装成功 | 判据里有"缺件时如实报"的格子 |
| ⑤ | **不越权**：鉴权失败一律拒（fail-closed）；不在协议层替对方说话 | 判据里有"无令牌必被拒" |

协议没落地，拓扑就是空转；拓扑没建模，协议就只是通道。**先修通道，再造规则。**
