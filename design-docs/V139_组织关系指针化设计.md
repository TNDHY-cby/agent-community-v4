# V139 · 组织关系指针化（`reports_to`）—— 把"谁向谁汇报"从**命名约定**变成**数据**

> 状态：**已拍板并落地**（老板 2026-11-09「1可以」；起因＝竞品雷达 `20261108_学习借鉴.md` §二 A1）
> 影响面：名单输出多两个字段、新增一个只读端点；**不改任何既有判断逻辑**（加法，不替换）
> 回滚：`AC_ORG_CHART=0` 时 `org-chart` 端点 404、roster 不带新字段（一处开关）

---

## 一、问题：现在我们靠"名字叫 `_lead`"来认组长

工作间里谁向谁汇报，**没有任何数据表达**，全靠两条隐含约定：

1. 名单里 `岗位: _lead` 的那个工位是组长（`platform/squads.py` 里写死「组长不进分队」）；
2. `岗位: 前端组/员工01` 这种带斜杠的名字暗示"属于前端组"。

后果（真实的，不是假想）：

- 前端要显示"谁听谁的"时**只能猜**：拿 `_lead` 这个字面量去比，或按 `/` 切名字；
- 一个新接入的 agent 想弄清"我应该向谁汇报"，从数据里读不出来（读 `_lead` 是**实现细节泄漏**）；
- 将来要加"分队长"这一层时，没有任何字段能承载 —— 只能再发明一个命名约定。

竞品（paperclip）的做法是 `reportsTo` 自引用外键 + `(companyId, reportsTo)` 复合索引：
**层级是数据，不是约定**。

## 二、目标（说清"做什么"，更要紧的是"不做什么"）

**做**：

| 字段 | 含义 | 取值 |
|---|---|---|
| `reports_to` | 这位向谁汇报（槽位名） | 组长 = `null`；成员 = `"_lead"` |
| `level` | 层级（0 最上） | 组长 = `0`；成员 = `1` |

新增只读端点 `GET /api/workshop/{id}/org-chart`：返回 `nodes`（扁平）+ `edges`（边）+ `unassigned`（没编进分队的人）+ `counts`。

**不做（说清边界，避免做出个"看起来有组织能力"的假功能）**：

- **不发明"分队长"这一层**。我方现在的分队（squad）是**分组**，不是层级；
  `squads.py` 里没有任何 leader 概念（实测确认），我**不替老板加**一个新的角色；
- 不把 `_lead` 槽位改掉。它是**现有身份来源**（派活闸门、`lead-todo`、`presence` 都靠它），
  动它就是动主流程 —— A1 要的是**表达**，不是**重构**；
- 不排分、不推荐、不评估谁该当组长（`no score/rank` 是全项目口径）。

**所以 A1 现在能给的，诚实说就两件**：

1. **把约定变成数据**：`reports_to`/`level` 出现在 roster 与 `org-chart` 里，前端和 agent 不必再比 `_lead` 字面量；
2. **为多层留位**：将来若要做"分队长 → 成员"，只需让 `reports_to` 能取分队长的槽位，**结构不用再改**。

**它现在还不能表达多层组织** —— 因为现在**没有**多层组织。这一点不许在文档/汇报里夸大。

## 三、影响面

| 位置 | 变化 | 风险 |
|---|---|---|
| `platform/org_chart.py` | **新增**（纯函数：输入名单/分队/任务，输出树） | 无（新文件） |
| `routers/presence.py` 新增 `GET …/org-chart` | 只读，不写盘 | 低 |
| `GET …/roster` 每个成员 | 多 `reports_to` / `level` 两个字段 | 低（**只加字段，不改既有字段**） |
| 判据 | 新增 `tools/org_chart_check.py`（6 格） | — |

**不改**：派活闸门、`lead-todo`、`presence` 的失联判定、`squads` 的建/改/停逻辑。

## 四、回滚

```powershell
$env:AC_ORG_CHART=0     # org-chart 端点 404；roster 不再带新字段
```
默认 `1`（开）。开关只有一处（`org_chart.enabled()`），不散落。

## 五、验收（判据 `tools/org_chart_check.py`，真跑临时实例）

1. 组长 `level=0` 且 `reports_to=null`；
2. 每个成员 `level=1` 且 `reports_to="_lead"`；
3. 成员带 `squad_id`（有分队时），但**分队长不是上级**（`reports_to` 仍是 `_lead`）；
4. `edges` 数量 = 成员数，且每条都是 `成员 → _lead`；
5. `unassigned` 列出没编进分队的人（**只列事实，不给建议**）；
6. `AC_ORG_CHART=0` 时端点 404（开关真生效，不是假开关）。

## 六、与竞品的差距（诚实对照）

| 竞品 | 我方 | 差距说明 |
|---|---|---|
| `reportsTo` 自引用 FK（可任意多层） | 只有两层 | 我方确实只有两层组织；多层是**将来的需求**，不是现在缺的功能 |
| `(companyId, reportsTo)` 复合索引 | 无索引（json 账本） | 规模不上万，用不上 |
| status 与 lastHeartbeatAt 分离 | 已有（`state` + `last_seen_ts` + `state_reason`） | **我方已达标**（见 A5，本来就不缺） |
