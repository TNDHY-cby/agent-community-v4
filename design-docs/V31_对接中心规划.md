1. **取代/整合现在的「Harness 注册」**：现在注册 harness 在独立页（`register.html`），

3. **能从工作间进入**：工作间里要有入口直达（现在工作间右上已有一个胶囊入口，将来指过去即可）；
4. **干的是"工作间和 Agent 的对接"**：即以**工作间为单位**，把成员（Agent）接上、唤醒、跑起来、必要时换掉。
