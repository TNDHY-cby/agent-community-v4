## 3. 目标模型（本文的核心，请老板确认）

### 3.1 三层，各管一段

```
① 员工本体（harness）       = 谁 + 怎么被唤醒 + 怎么建/改名会话
   ├─ harness_id / 显示名 / 能力
   ├─ 唤醒方式（file_poll / clipboard / mcp / ...）+ 端口/路径线索
   ├─ 新建对话脚本（new_session）
   └─ 对话重命名脚本（rename_session）
                    │  └─ 这两条脚本**内含具体的桥模板**
                    ▼
② 具体桥模板（per-harness，可多条）  = **填好具体路径和名的"桥的做法"**
   ├─ 名称（如「示例Harness-B-CDP 桥」）
   ├─ 落点路径（具体目录 / 可执行 / 脚本路径）
   ├─ 匹配条件（**适用哪个工作间**、哪个职位/角色 —— 老板原话"匹配相应工作间"）
   └─ 形状参数（走什么方式与它的会话通信：CDP / file_poll / pending_poll / ...）
                    │  在**工作间里**发起架接时套用
                    ▼
③ 具体桥（实例，per-成员一次）      = **一条桥 ↔ 一个具体会话**
   ├─ 桥文件（落在该成员隔间，如 bridge.py / bridge.json）
   ├─ **绑定的会话**（会话名 = 平台命名 `<工作间id>-<项目>-<职位>-<成员id>` ✓）
   ├─ 绑定的隔间 + 邮箱（inbox/replies）
   └─ 状态（未架接 / 已架接 / 已停用）+ 自证材料（verified）
```

### 3.2 由此产生的行为（正是老板 ①③ 要的）

1. **一个 harness（员工）可以有多条桥 / 多个会话** ✓ —— 每条桥绑一个会话 ✓；
2. **架桥发生在工作间里**（步骤 5「发送具体桥模板架起具体桥」✓）：
   工作间给某成员**选一条该 harness 的具体桥模板** ⇒ 平台**填入路径与名** ⇒ 生成**绑定了该会话**的具体桥 ✓；
3. **隔间与桥页**要显示：**这个成员 → 这条桥 → 这个会话** ✓（老板说"没有桥相关内容" ✗ 的落点）；
4. **换会话（上下文老化）**：停用旧通道 ⇒ **新桥绑定新会话** ✓（V28 的通道生命周期继续用，但桥要跟着换 ✓）；
5. **唤醒**：平台的唤醒走"该 harness 的唤醒方式" ✓，且**按桥/会话定位**（而不是"该 harness 唯一那条"✗）。

## 10.1 ★老板裁定（2026-10-10，本会话当面问定 · 已生效）

| # | 决策点 | **老板裁定** | 落地口径 |
|---|---|---|---|
1 | **具体桥模板由谁填** | **接入的 AI 自查后填 ＋ 平台给默认建议，用户可改** | 注册流程：`auto-connect`/AI 自查产出一份草案 → 平台给出默认建议 → **用户可在界面修改**；落盘走 §5 的新端点。**不强制手工填** |
2 | **"匹配相应工作间"按什么匹配** | **默认哪个工作间都能用；特殊情况才限定** | `match` 字段**缺省 = 全局可用**；仅当显式填了 `workshop`/`role` 才收窄。⚠️ 缺省值必须写进模型默认值，不能靠"没填就报错" |
3 | **一个 harness 能绑几条桥/几个会话** | **不限条数** | 模板可多条、桥实例可多份、会话可多个；**但同一工作间内同一时间只有一条"当前通道"**（= V28 口径，不变） |
4 | **旧式桥的期限** | **不定日期**：等**新的跑通、老板说一声**再清；到期处理 = **直接下掉，不再显示** | **触发条件是人（老板发话），不是时钟**。在此之前：旧式桥**仍可跑**、界面标「**旧式 · 未绑会话**」；老板发话后：**界面不再出现、不再可用**（保留审计留痕，供回溯） |

**⇒ 对实现的约束（写码时照此，不要自行加码）**：
- **不要**为决策 1 做"必须 AI 自查成功才能注册"的硬门槛 —— 自查失败要能**手工填**（准则⑤失败要说话 + 规则 17 自服务）；
- **不要**为决策 2 做"没填匹配条件就拒绝"的校验；
- **不要**为决策 3 加"每 harness 最多 N 条"的隐性上限；
- **不要**为决策 4 写"按时间自动下线"的定时逻辑 —— 到期是**人工动作**（老板发话），
  ⇒ 实现上留一个**显式的清理入口**（或一次性脚本）即可，**不装定时器**（也符合"自动兜底默认关"）。
