## 1. 选定口径（三条）

1. **两条路并存，但主次要分清**：对接中心的登记面板**首选**「把这段发给你的 AI」（①），
   平台探测表单降为**次选**「或者你自己填」（②）。理由：① 不需要用户懂任何技术细节，
   而且**它让 agent 自己把该填的填对**（这正是"外端 agent 生产合作社"的产品语义）。
2. **话术只有一处真相**：话术**由后端生成**（新端点），前端只做**展示 + 复制**；
   `register.html` 的静态话术**改为指向新位置**（内容保留作历史与自测题）。
3. **不许两份口径**：话术里的"要几步/配哪种桥/等级表"必须来自 `interface_guidance`（同一份数据），
   **不在前端再抄一遍**（规则 20）。

## 2. 数据与接口

### 2.1 新端点（注册**前**用）

```
GET /api/harness/register-prompt?platform_url=<可省>&wakeup_method=<可省>&format=text|json
```
- `platform_url` 省略时用平台唯一地址解析点（`platform_address`）——**不许写死端口**；
- `wakeup_method` 省略 ⇒ 返回"通用三段"（不预设接口）；给了 ⇒ **按该接口定制**
  （复用 `interface_guidance.flow_text` 的同源数据，含"你要做哪几步/配哪种桥/等级"）；
- `format=text`（默认）返回 `{"prompt": "<整段话术>", "source": "interface_guidance"}`，
  `format=json` 返回结构化字段（供前端分块渲染，如"要几步/证据要求/自检命令"）。

### 2.2 话术里必须有（判据可查）

1. **平台地址**（真实端口，来自解析点）；
2. **你要做什么**：`POST /api/harness/register`（最小必填字段 + 一句示例 JSON）；
3. **按你的接口分行的"要几步"**（与 `interface_guidance` 同源，不许前端另写）；
4. **怎么自验**：`POST /api/harness/{你的id}/verify`（**没跑过就不许说通**）；
5. **卡住怎么办**：第二通道 `POST /api/assistant/chat`；
6. **一句话纪律**：先把 `GET /api/protocol-brief` 拉下来读（它是机器可读的"怎么配合"）。

## 3. 前端改法（**归 MiMo**，契约由我提供）

`docking.js` 的登记面板改成两栏（同一张卡里）：

| 栏 | 内容 |
|---|---|
| **首选**「把这段话发给你的 AI」 | 一句话说明 + `<pre>` 话术正文（只读、可滚动）+ **复制按钮**（复制成功要有反馈）+ 一句"它注册完会让平台自己登记，你回来刷新即可" |
| 次选「或者你自己填」 | 现有的探测表单（① 探测并登记 / ② 只存草稿） |

⚠️ 三条不许：① **不许前端自己拼话术文本**（必须来自 `register-prompt`，否则又是一份口径）；
② **不许**把"复制成功"当成"已经注册成功"（三态如实：复制≠注册≠验证）；
③ **不许**在话术里写死端口/本机路径。

## 4. 判据（拍板后做成守卫）

| # | 判据（真跑） |
|---|---|
| 1 | `GET /api/harness/register-prompt` 返回的话术里**含真实端口**（换 `AC_PORT` 起实例 ⇒ 话术里的地址跟着变） |
| 2 | 话术里含 `POST /api/harness/register` 与**最小必填字段**；给 `wakeup_method` 时**按接口分行**（与 `interface_guidance` 输出逐字一致） |
| 3 | 话术里含自检命令 `POST /api/harness/{id}/verify` 与第二通道 |
| 4 | **把话术原样发给一个"假 agent"脚本**（测试用）⇒ 它能只看话术就完成注册（**端到端**：这是本稿的真正判据） |
| 5 | `docking.js` 的登记面板里**有复制按钮且文本来自端点**（静态守卫）；`register.html` 顶部指向新位置 |
| 6 | 话术**不含**本机绝对路径 / 固定端口（发布面扫描 fail=0） |

突变检验：把"话术来自端点"改成前端写死、把"自检命令"删掉、把"按接口分行"去掉 ⇒ 守卫必须变红。

## 5. 不做

- ❌ 不自动替用户"发给 AI"（平台没有直接对话外端 agent 的通道，**如实说**：这一步必须人来粘）；

- ❌ 不改"注册后引导"（`next_steps_text` 已同源）。
