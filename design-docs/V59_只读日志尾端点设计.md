# V59 · 只读日志尾端点 `GET /api/logs/tail` 设计（2026-10-19）

> 需求来源：前端负责人（通道 177/184）——启动过场的"片尾字幕"目前是**演示文本**，
> 想绑**真日志**；但**不许**把日志文件路径暴露给浏览器、也不许给前端开"读任意文件"的口子。
> 老板 2026-10-19：「继续开发吧，先把核心完善了」⇒ 本稿即实施稿。

## 1. 一句话

平台提供一个**只读、只白名单、只尾部、已去敏**的端点，让界面能把"刚刚发生的事"显示出来；
**它不能读任意文件，也不能改任何东西**。

## 2. 请求与响应

```
GET /api/logs/tail?name=server&lines=50&since=0
```

| 参数 | 说明 |
|---|---|
| `name` | **白名单名**（不是路径）：`server` / `watchdog` / `a2a` / `grpc`。默认 `server` |
| `lines` | 要多少行（默认 50，**上限 200**；超了按上限给并标 `truncated=true`） |
| `since` | 可选：只要"行号 > since"的新行（用于轮询追尾；不传就取最后 `lines` 行） |

响应：

```json
{
  "success": true,
  "name": "server",
  "file": "<实际读取的绝对路径（仅本机调用方可见；界面不要显示它）>",
  "lines": [{"n": 1281, "text": "..."}],
  "total_lines": 1283,
  "next_since": 1281,
  "truncated": false,
  "redacted": 1,
  "note": "..."
}
```

## 3. 四条硬边界（**做不到就不做**，不许"先开了再说"）

1. **只白名单**：`name` 只认四个固定的名字，映射到固定的文件；**任何路径字符都不接受**
   （`../`、盘符、绝对路径一律 400，并说清"只支持这四个名字"）。
2. **只读**：仅 `open(..., "r")` 读；不创建、不截断、不清理、不加锁；读失败**如实报错**。
3. **只尾部**：最多 200 行；超大文件用**从尾部回溯读**（不全量载入内存，避免把服务器拖死）。
4. **去敏**：命中凭据样式的片段替换为 `***`（`sk-…`、`Bearer …`、`token=…`、`password=…`、
   `X-Agent-Token:`、`AC4_TOKEN=…`），并在响应里给出 `redacted` 计数（**如实说去了几处**）。

> **不做**：不做"按关键字搜索"、不做"下载整份日志"、不做"清理日志"、不做"跨实例读别人的日志"。
> 这些要么是运维动作（不是界面该有的）、要么会变成读全盘的通用口子。

## 4. 谁能调

- **只本机来源**（复用 `platform/routers/system.py::origin_allowed()`）⇒ 非本机 `403`；
- 配了 `AC4_SHUTDOWN_PIN` 时**不额外要口令**（只读、且只本机），但**记审计**：
  `system.logs_tail`（谁调的、哪个文件、多少行、去敏几处）。

## 5. 前端怎么用（契约一句话）

字幕轮询：首次 `GET /api/logs/tail?lines=50` 拿到 `next_since`；之后每 2~3 秒
`GET /api/logs/tail?since=<上次的 next_since>`，只渲染新行；**界面不显示 `file` 字段**。

## 6. 判据（`tools/logs_tail_check.py`，真跑）

| 格 | 判据 |
|---|---|
| ① | 取尾部 N 行：顺序正确、最后一行 = 文件最后一行 |
| ② | 上限生效：请求 1000 行 ⇒ 实际 ≤200 且 `truncated=true` |
| ③ | **穿越被拒**：`name=../secret`、`name=C:\x.log`、`name=server.log` 一律 400，且**不返回任何文件内容** |
| ④ | **去敏生效**：日志里的假凭据被替换成 `***`，响应正文里**搜不到**原值；`redacted ≥ 1` |
| ⑤ | **只读**：读前读后文件 size/mtime 不变（含"不创建新文件"） |
| ⑥ | 非本机来源 ⇒ 403 |
| ⑦ | 轮询追尾：带 `since` 只返回新行；再次带同一个 `since` 不重复给 |
| ⑧ | 审计有 `system.logs_tail` |
