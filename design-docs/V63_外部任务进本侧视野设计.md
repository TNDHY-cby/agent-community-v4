# V63 · 外部任务进本侧视野（跨公司那一段要看得见）（2026-10-20）

> 承接 V62：`/api/peers/{id}/dispatch` 已经能把活真投给对端公司（**16 格判据全绿、真机演示通过**）。
> 但投出去之后**本侧什么都不留**：看板、任务树、审计里都看不到"我们派过一趟活给外部公司"。
> 老板要的是"接着做"，这条把它补上。

## 1. 用户看到什么

| 位置 | 现在 | 这条做完 |
|---|---|---|
| 对接中心 | 只有对端公司列表 | 多一块「**对外任务**」：标题、投给谁、状态、什么时候投的、回执几时回 |
| 工作间（可选关联） | — | 如果这趟活是从某个工作间派出去的，那个工作间里能看到它 |
| 运维看板 / 审计 | 看不到 | 审计有 `peer.task.sent` / `peer.task.refresh` |

## 2. 关键设计：**不建内部工作间**（别误触发员工动员）

派给外部公司的活，**不能**走"建工作间"那条路——那会触发讨论、动员、通道分配，等于把自己的员工叫来干别人公司的活。

⇒ 单独一类一等记录：**外部任务（peer task）**，落 `<AC_DATA_DIR>/peer_tasks.json`。

```json
{
  "pt_3f2a1b": {
    "pt_id": "pt_3f2a1b",
    "peer_id": "co-b", "peer_name": "公司 B",
    "title": "把登录页错误提示统一口径",
    "workshop_id": "ws_xxx",           // 可选：从哪个工作间派出去的（空＝总控直派）
    "remote_task_id": "2c289baa",       // 对端那边的任务号
    "status": "sent|working|done|failed|unreachable",
    "created_at": "...", "updated_at": "...",
    "last_check": {"at": "...", "status": "working", "detail": "..."},
    "timeline": [{"at": "...", "event": "sent", "detail": "已投给 co-b"}]
  }
}
```

**状态语义（诚实优先）**：

| 状态 | 含义 | 怎么来的 |
|---|---|---|
| `sent` | 已投出去，对端还没回话 | 派活成功后立刻置 |
| `working` | 对端说在做 | 回查得到 |
| `done` / `failed` | 对端说完成/失败 | 回查得到 |
| `unreachable` | **够不着对端**（隧道断/服务停） | 回查失败时置——**绝不留在 `working` 假装还在跑** |

## 3. 端点（接在 `/api/peers` 那组旁边）

| 端点 | 作用 |
|---|---|
| `POST /api/peers/{id}/dispatch` | **已有**，扩展：可选 `workshop_id`；成功后**同时**建一条外部任务记录 |
| `GET /api/peer-tasks` | 列表（支持 `peer_id` / `workshop_id` / `status` 过滤） |
| `GET /api/peer-tasks/{pt_id}` | 单条详情（**只读本地记录**，不发网络请求） |
| `POST /api/peer-tasks/{pt_id}/refresh` | **真去查对端**并更新状态（人点才查，不自动轮询） |

- 全部本机来源；审计 `peer.task.sent` / `peer.task.refresh`；
- 列表按时间倒序，带"多久前"的时间戳（界面直接显示）。

## 4. 判据（在 `cross_company_check.py` 的 16 格后加 3 格）

| 格 | 判据 |
|---|---|
| ⑯ | 派活后**本侧立刻能看到**这条外部任务（`status=sent`，带 `remote_task_id`） |
| ⑰ | `POST /api/peer-tasks/{id}/refresh` ⇒ 状态从 `sent` 变成对端真实状态，`last_check` 有记录；**时间线追加一条** |
| ⑱ | 按 `workshop_id` 过滤生效；对端**停掉后** refresh ⇒ 状态变 `unreachable`（**不许留在 working**） |

## 5. 界面（归前端，我给契约）

对接中心加「对外任务」区块：列表（标题 / 投给谁 / 状态 / 何时投 / 回执）+ 单条「刷新回执」按钮。
若与工作间关联，工作间里显示一行「已派给外部公司：<标题>（<状态>）」。
