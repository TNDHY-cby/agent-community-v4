# V88 监控室：把外端 harness 的窗口画面拿回来（**已拍板 · 已实施 4.35.0**）

> 老板 2026-10-22：现有监控室只有"代码级映射"，要**看得见画面** ——
> 一个墙上一眼看到所有在跑的 harness（窗口可以放到角落/被别的窗口挡住），
> 需要时点开放大；平台 agent 也能做**简单观察**。
>
> 本稿**先做了真机验证**（§1），再给方案。**未写实现，等拍板。**

## 0. 一句话

用 **Windows 的窗口抓取**（PrintWindow 为主、WGC 兜底）抓**用户显式选中的窗口**，
在本平台里做成一面**不打扰用户的画面墙**：被遮挡也能看、点开放大、不抓就停。

| # | 我问的 | 老板答的 | 落地口径 |
|---|---|---|---|

## 0.2 追加口径（2026-10-22，老板）：**开关就在监控室里**

> 老板原话：「**监控的开始和关闭都在监控室里面进行**」。

⇒ 产品硬约束：**用户不该为了开监控跑去对接中心**。监控室页面必须自己完成：
「看到能开哪几个 agent → 就地开 → 就地关」。

落地（本版已实现）：
- 新增 **`GET /api/monitor/agents`** —— 监控室的**选择器**数据源，一次给全：
  `harness_id / harness_name / status`、`bridge{status, ready, why}`、`eligible`、
  `monitor{on, state, why}`、`window{hwnd, resolved_by, can_capture, why}`、`last_ok_at`；
  **能开的排最前面**，其次按名字。
- 开关就是就地一个调用：**`POST /api/monitor/watched {harness_id, on}`**（同一页面上调用）。
- 「能开」的唯一口径（一处真相）：`bridge_status == "tested"`
  （词表在 `protocol.py`：`""`未登记 / `"reported"`只登记路径 / `"tested"`桥测试真通过）。
  **`reported` 不算通** —— 名单里会出现但 `eligible=false`，并说清"先去把桥测通"。
- `can_capture` 三种值都允许且**含义明确**：`true` 抓过且成功 / `false` 有具体原因
  （窗口关了、最小化了、没认出来）/ **`null` = 还没试过（不猜）**。
  列表**绝不现场抓图**（那是取帧的事），所以这个端点可以放心给页面频繁调。

## 1. 现状核实（2026-10-22 真机实测，不是读代码）

| 事实 | 结论 |
|---|---|
| 现有 `GET /api/harness/{id}/mirror` | **只有代码级**映射（CDP 文本 / 协议状态），**没有像素** |
| 现有"点画面→激活窗口" | 已有：`_activate_windows_by_pids`（Windows 专用，非 Windows 如实不支持） |
| `PrintWindow(hwnd, PW_RENDERFULLCONTENT)`（**纯 ctypes，零依赖**） | **能抓**：本机 8 个真实窗口里 **6 个成功**（DeepSeek Harness / Edge / ZCode / 微信 / 文件资源管理器 ×2） |
| 同法**抓不了的** | **2 个**：Marvis（Electron/GPU 合成）、`Shell Handwriting Canvas`（特殊 canvas）→ **恒为整张黑图**，可用"全黑检测"如实判定失败 |
| WGC（`Windows.Graphics.Capture`） | 本机**没有** `winrt` / `windows-capture` ⇒ 当前不可用；需可选依赖才能走 |
| Pillow | **没装**（也不在 `requirements.txt`）⇒ 现在**出不了 JPEG**，MJPEG 流做不了 |
| 最小化窗口 | PrintWindow/WGC 都**抓不到**（老板已知："不能最小化"） |

⇒ 三条设计结论（都由实测逼出来的）：
1. **零依赖也能看到画面**：PrintWindow + GDI `StretchBlt` 缩小 + **PNG（zlib，标准库）**编码，
   不需要装任何包；只是**帧率低**（1–2 帧/秒的快照墙），够"一眼看到"；
2. **WGC 是补救不是前提**：只对"PrintWindow 抓黑"的窗口有价值，必须**可选依赖 + 装了才亮**；
3. **必须能如实说"这个窗口抓不了"**：黑图检测 + 报出窗口类名与建议（"用 WGC 试试 / 这窗口受保护"），
   绝不拿一张黑图当"正常画面"。

## 2. 目标 / 非目标

**目标**
1. 画面墙：一次看到 **N 个**（默认上限 6）harness 窗口的实时画面，窗口被遮挡/在后台也能看；
2. 点开放大：同一路流的**原始尺寸**快照（不额外抓取，避免两套口径）；
3. 不打扰：不抢前台、不改窗口位置、不最小化别人的窗口（与 V51 §5 同一条纪律）；
4. 平台 agent 能"简单观察"：**变化检测**（默认开，零成本）+ **可选一句话点评**（默认关，走 AI 要花钱）；
5. 非 Windows / 抓不到 / 没装可选项：**一律如实说**，不假装成功。

**非目标（明确不做）**
- ❌ **不录屏落盘**、不做历史回放、不做"你不在也一直在录"；
- ❌ 不抓全屏、不抓未选中的窗口、不抓"受保护内容"（DRM/银行类）；
- ❌ 不做远程看画面（**画面不出本机**；外部只读档**永远**看不到）→ 见 §4；
- ❌ 不上 OCR/人脸/内容识别（V25 §5 的依赖纪律：这些是可选组件，不进核心）。

## 3. 契约（新模块 `platform/monitor.py` + `routers/monitor.py`）

### 3.1 抓取层（一处真相）

```
capture.sources()                      → 可抓窗口列表（hwnd / pid / title / 尺寸 / 是否已选 / 是否和某个 harness 对得上）
capture.grab(hwnd, max_w=0, fmt="png") → {ok, fmt, w, h, bytes, method, why}
```
- **方法阶梯**（每一步都**报出自己用的哪种**，不许静默换）：
  1. `printwindow` —— 纯 ctypes；`PW_RENDERFULLCONTENT` 失败再试 `0`；
  2. `wgc` —— 仅当装了可选依赖（`windows-capture` 或 `winrt`）且 `printwindow` 报黑；
  3. 都不行 ⇒ `{ok: false, why: "抓不到（窗口可能是 GPU 合成/受保护）", hint: "…"}`。
- **编码**：`png`（zlib，标准库，零依赖）为默认；`jpeg` 仅当 Pillow 存在（用于 MJPEG 连续流）；
  `bmp` 仅调试用。
- **缩小**：GDI `StretchBlt` 到 `max_w`（墙上的瓦片默认 320px），**放大看**时才抓原尺寸。

### 3.2 端点（全部在 `/api/monitor` 下）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/monitor/sources` | 可抓窗口 + 每路"能不能抓/用什么方法/为什么抓不了"（**一处真相**） |
| GET | `/api/monitor/agents` | **监控室的选择器**：能开哪几个 / 为什么不能开 / 现在开没开（就地开关） |
| GET | `/api/monitor/watched` | 已选名单（含每个的 harness 关联、最后一张是否成功） |
| POST | `/api/monitor/watched` | 加/删一个（`{hwnd, on}` 或 `{harness_id, on}`）**写请求** |
| GET | `/api/monitor/{id}/frame?max_w=320` | 单帧（PNG；放大就是 `max_w=0` 的同一路） |
| GET | `/api/monitor/{id}/stream` | MJPEG 连续流（**仅 Pillow 存在时**；否则 501 + 怎么装） |
| POST | `/api/monitor/{id}/observe` | 简单观察：`{changed, diff_ratio, last_ok, note}`；`ai=1` 时给一句话点评（默认关） |
| GET | `/api/monitor/health` | 方法可用性/依赖/Pillow/上限/最近失败原因 |

**纪律**：`frame` 与 `stream` 是 **GET**（只读、幂等）；`watched`/`observe` 是写请求 ⇒ 进前台白名单。

### 3.3 "简单观察"怎么做（不烧钱）

- **默认只算变化**：把上一帧的缩略图做块哈希，`diff_ratio > 0.02` 才算"画面变了"；
  连续 3 次没变化 ⇒ `note="这页大概 3 秒没动过（可能卡住）"`（零成本、纯本地）；
- **AI 点评**默认**关**（`AC_MONITOR_AI_OBSERVE=0`）：开了才把**一张 320px 缩略图**发给已配置的 AI，
  问一句"这页有没有报错/卡住/等输入？一句话"，并**限流 1 次/分钟、每窗口每天最多 60 次**；
  每次都写审计（谁看、看了哪个窗口、花了多少钱按既有 usage 记账）。

## 4. 隐私与安全（这一块比功能重要）

1. **必须用户显式选**：不选就不抓；列表**只存** `hwnd/pid/title/harness_id`（`data/monitor/watched.json`）；
2. **重启不自动开抓**：名单恢复但状态一律 `stopped`，要用户再点一次（防"上次忘了关，一直在录"）；
3. **没有查看者就停**：`stream/frame` 连续 60 秒没人拉 ⇒ 自动停抓（不后台空转）；
4. **画面不出本机**：`/api/monitor/*` 进 `EXTERNAL_READONLY_DENY`（外部只读档一律 403），
   并**不提供**任何"把帧发到别处"的端点；
5. **留痕**：`monitor.start / monitor.stop / monitor.observe(ai=1)` 都进 `audit_log`；
6. **受保护窗口**：抓黑即判失败并如实说，不重试、不绕过（不做任何"绕过 DRM/安全桌面"的尝试）。

## 5. 判据（按真结果写）

| # | 判据 | 怎么验 |
|---|---|---|
| 1 | 抓不到就说抓不到 | 对 Marvis/Canvas 这类窗口 ⇒ `{ok:false, why}`，**不是**一张黑帧 |
| 2 | 抓到的是真画面 | 对已知窗口抓一帧，**像素方差** > 阈值（不是纯色/噪声） |
| 3 | 方法可追溯 | 每帧带 `method`（`printwindow`/`wgc`），日志与审计里能对上 |
| 4 | 没 Pillow 也能看到 | 卸载 Pillow 环境下 `frame` 仍 200（PNG）；`stream` 返回 501 + 安装命令 |
| 5 | 没选就不抓 | 未选窗口 `frame` ⇒ 403/404，且**没有任何抓取动作**（打桩断言 capture 没被调） |
| 6 | 无人看就停 | 停拉 60 秒后 `watched` 里该路 `state=stopped`，再拉一次能自动恢复 |
| 7 | 画面不出本机 | `EXTERNAL_READONLY_DENY` 包含 `/api/monitor`；只读档访问 403 |
| 8 | 变化检测真的省钱 | 静态画面下 `observe` 不触发 AI（打桩断言 AI 未被调用）；有变化才触发 |
| 9 | 非 Windows 如实不支持 | 非 Windows 下所有端点 501/`{ok:false,why:"只在 Windows 上支持"}` |

## 6. 明确不做

- 不做录屏/回放/历史；不做远程转发；不做 OCR/内容识别；
- 不做"自动盯漂不漂"的后台巡检（要用户或 agent 主动看）——避免变成监控软件；
- 不碰 `frontend/**`（墙的界面归前端负责方，本稿只给契约）。

## 8. 实施记录（4.35.0，2026-10-22）

**落点**：`platform/monitor.py`（抓取/编码/名单/观察/闸门）+ `routers/monitor.py`（6 个端点）
+ `tests/test_monitor.py`（17 条判据，含 2 条平台相关如实 skip）。

| 项 | 实现 |
|---|---|
| 抓取 | `PrintWindow(PW_RENDERFULLCONTENT)` → 失败再试 `0`；**黑图检测**判失败；最小化如实拒绝 |
| 编码 | 标准库 `zlib` 手写 PNG（不引 Pillow）；缩小用整数采样 |
| 方法可追溯 | 每帧响应头 `X-Monitor-Method`，`health.methods` 列出可用方法 |
| 监控对象 | **agent**：`POST /api/monitor/watched {harness_id, on}`；hwnd 由 `pid`/`harness_name`/`harness_id` 解析，认不出就报原因并允许手动指定一次 |
| 上限/帧率 | `AC_MONITOR_MAX_WATCH`（默认 6）、`AC_MONITOR_FPS`（默认 1） |
| 无人看自动停 | 超过 60 秒没人拉 `frame` ⇒ `state=stopped` 并写原因 |
| AI 观察 | 默认关；开了也必须过**≥30 分钟**的间隔闸门；**本版不调用模型**（不假装看图），只做本地变化统计 |
| 安全 | `/api/monitor` 进 `EXTERNAL_READONLY_DENY`；start/stop/observe 全进审计 |

**真机实测（本机 14 个窗口）**：
- 抓到并**肉眼确认是真实画面**：DeepSeek Harness（480×568 PNG 25 KB，`printwindow`）；
- 抓不到且**如实报**：Marvis（Electron-GPU 合成）、`Shell Handwriting Canvas`（系统不让抓）；
- 同一窗口连抓 3 帧签名**完全一致**（`diff=0.000`）⇒ 变化检测稳定、不是噪声；
- 窗口内容真的滚动时 `diff` 会跳起来（0.975）—— 那是**真变化**，不是误报。

**两处实现时修掉的自己的错**：
1. `_state_path() + ".ai"`（Path 加 str）⇒ `TypeError`；改成独立 `_ai_path()`；
2. `jpeg_available()` 里写了 `import PIL` ⇒ 被 `test_foundation_base` 的第三方 import 守卫抓到
   （Pillow 是可选依赖，不该 import）⇒ 改成 `importlib.util.find_spec("PIL")`。
