# V99 · 对接中心注册链路（老板 2026-10-25 口述的 5 步，**这就是界面骨架**）

> **口径来源＝老板原话**（下面 §1 原文照录，别再 paraphrase 成另一套）：
> 「做成：1.询问协议（若已知可手动跳过）；2.选择协议（选择协议后，才进行真注册，
> 选择不同的注册给出不同的适配的功能卡片，不要全乱放一起，做成树状链路）；
> 3.复制对应注册引导（给agent看的，用.md格式就行）给外端agent；这里留给（脚本注册之类的）；
> 4.检测；5.平台与agent对话框（人工搬运）……」

## 1. 五步（顺序不许颠倒；第 1 步可跳过）

| 步 | 做什么 | 界面上长什么样 | 后端 |
|---|---|---|---|
| **1 问协议** | 平台先猜：能被命令拉起？盯目录？有常驻 HTTP？是 MCP 服务？只能人工粘贴？ | 一句问 + `[帮我探一次]` + `[已经知道，跳过]` | 已有探测（进程/端口/HTTP）；跳过就是直接进第 2 步 |
| **2 选协议 → 才真注册** | **选定协议之后才发起真注册**；不同协议挂**不同的功能卡片**，树状挂在协议下面，**不平铺** | 6 个协议各一行（可展开）；展开后只显示该协议的卡片 + 必填字段 + 注册按钮 | `GET /api/docking/protocol-tree`（一处真相）+ `POST /api/harness/register` |
| **3 复制注册引导（.md）** | 把**该协议专属**的登记话术以 Markdown 复制给外端 agent，让它自己登记；**这一页也留给脚本注册**（桌面型在这里截图/框选/配脚本） | `[复制 Markdown]` + 一段预览；桌面型多一块「框选输入框/配脚本」 | `GET /api/harness/register-prompt?wakeup_method=<协议>&format=md` → `text/markdown` |
| **4 检测** | 注册完**当场验一次**，不靠猜 | 表里每行 `[测一次]` + 上次结果（✅/⚠ + 原因 + 用时） | `POST /api/docking/harness/{id}/test-now`；结果写档案 `metadata.last_test`，`overview` 每条带 `last_test` |
| **5 跟它对话（人工搬运）** | 平台把话放可复制的框，人粘过去；对方的回答人粘回来 | 两栏：`平台→它` / `它→平台`；一个 `[我确认它回了]` | 半自动：不假装能核实；确认动作要留痕 |

## 2. 协议 → 功能卡片（树，不再平铺）

`protocol_tree.py` 是**唯一数据源**；界面照着渲染，**别在 JS 里再抄一份**。

| 协议 | 能被平台叫醒 | 要不要桥 | 要开会话 | 卡片（挂在协议下面） | 检测方式 |
|---|---|---|---|---|---|
| `mcp` | ✅ | 不要 | 不要 | 直推（无桥）/ 工具表 / 不需要新建会话 | 真调 `initialize`+`tools/list` |
| `http_api` | ✅ | 不要 | 不要 | 直推 / 无回调也要说清 | 真 GET 一次 |
| `acp` | ✅ | 不要 | 要 | 平台真拉起 / 要一个工作目录 | 走 `/verify` |
| `file_poll` | ❌ | 要 | 要 | 桥搬件 / 叫不醒 | 看桥有没有取走件 |
| `clipboard` | ❌ | 要 | 要 | 半自动 / 视觉激活 | 视觉自检 / 试投 |
| `http`（兜底） | ❌ | 要 | 要 | 只落盘 / 不假装能叫醒 | 看它来不来取件 |

**"空壳零容忍"**：不可用的行 —— 整行灰 + 一句话原因 + **按钮置灰**，不许出现点了没反应的按钮。

## 3. 判定"做完"的标准（老板可按这个验收）

1. 走完 1→5 步，中间**不需要问人**（每步都有"下一步做什么"）；
2. 每个按钮点了**都有真实反应**（真注册 / 真拉工具表 / 真测 / 真复制）；
3. 不可用的东西**看得出来**（灰 + 原因），不会点进空壳；
4. 「脚本注册」只在**桌面型**出现（协议型不需要），且始终写着**给谁**（名字 · 协议 · harness_id）。

## 4. 现在后端已就绪 / 前端要做的

**已就绪**：`protocol-tree`（五步 + 六协议卡片）、`register-prompt?format=md`（Markdown 引导）、
`test-now`（按协议自动测 + 写档案）、`overview.last_test`、`members`（MCP 类可直接加进工作间）。

**前端要做的**（照 §1 五步重排，不新增功能）：
- 顶部两条主线：`[注册 Harness]`（协议）/ `[配脚本]`（桌面型），其余收进详情抽屉；
- 第 2 步：协议列表可展开，展开只显示该协议卡片（数据来自 `protocol-tree`）；
- 第 3 步：一个 `[复制 Markdown]`（直接拿 `text/markdown` 那段的原文）；
- 第 4 步：表里每行 `[测一次]` + 显示 `last_test`；
- 第 5 步：两栏人工搬运 + `[我确认它回了]`。
