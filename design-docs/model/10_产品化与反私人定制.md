## 10b. 产品化与反私人定制模型

> 老板原话：「**以后再这样搞私人定制我们就死了**」（2026-10-11）、
> 「**完善开发框架，以后的开发也要注意产品不是私人订制的**（我说不清楚）」（2026-10-15）。
> "说不清楚"的部分已**落成可执行判据**；**唯一规则源＝仓库根 `PRODUCTIZATION.md`**，本节是模型视角的摘要。

**判据（一句话，验收可查）**：**换一个目录 + 换一个端口 + 换一个数据目录、不改一行代码就能走通。**
做不到就**如实说没做到**（不许"我这台能跑"充当验收）。

**六种"私人定制"形态 → 各自的检查器**（能自动查的一律自动查，CI 与 pytest 双入口）：

| # | 形态 | 检查器 | 现状 |
|---|---|---|---|
| 1 | 写死本机坐标（端口/IP/路径/用户名/凭据） | `tools/check_portability.py` | fail=0 |
| 2 | 代码/文档出现真实 harness 名或私有产品名 | `tests/test_bridge_catalog.py` 私有名守卫 | 通过 |
| 3 | **平台专属能力伪装成通用能力**（只有 Windows 能跑，别处静默失效） | `tools/check_productization.py` 规则 A | fail=0（欠账 3 处已显式申请例外并在 `PRODUCTIZATION.md` 登记） |
| 4 | **开箱默认塞假数据**（看起来配好其实必然失败；未渲染 `{{占位}}`） | `tools/check_productization.py` 规则 B | fail=0 |
| 5 | **只在我这台机器绿**（编码/换行/平台差异） | ★**CI 不拿当判据**（推 GitHub 会触发它，但结论不认），由**本机双平台真跑**承担：Windows 全量 `pytest` ＋ WSL Ubuntu 跑 `temp/run_linux_suite.sh`（另加 `test_bridge_encoding_guard.py`）| 两平台真跑均绿（Linux 侧解释器 ≠ Windows 侧，如实标注）|
| 6 | **用户第一次跑就撞到**（入口不可用 / 失败不说话 / 文档承诺未实现） | `tools/first_run_check.py` + `tests/test_cli_contract.py` | 全绿 |

**两个可执行验收工具（2026-10-15 新增，已进 CI）**：
- `tools/check_productization.py` —— **AST 级**扫描：只看真正的 `subprocess` 调用点（不扫注释/文档串，
  否则 52 条噪音、第一天就被绕过）；规则 A 平台专属命令、规则 B 未渲染占位；
  例外必须写 `# productization: allow(<理由>)`；**同时报告"平台专属 skip 清单"**（每条都意味着"这块在别的平台没守"）。
- `tools/first_run_check.py` —— 陌生人首次运行走查：clone → `cli start --no-gui`（**换端口+换数据目录**）
  → `cli task` → `cli task-result` → `cli stop`，外加"**仓库保持干净**"与"**错误不许是空原因**"。
  ⚠️它 clone **已提交内容** ⇒ 在 dev 里验收要 `--src <发布副本>`（否则测的是 dev 的旧提交，会**假红**——实测踩过）。

**开发模式（DSH agent preset `ac-dev`）已同步更新**：L1 人设（每步注入、逐字节稳定）加入
「**产品不是私人定制**」判据与两个工具的调用点；L2 手册（技能 `ac-project-dev`）补工具与判据。
⚠️ 模式**只影响新会话**（机制决定）——要拿到新人设必须**开新会话**并选「合作社开发模式」。

发布 = `publish_acv4.ps1 -Target gitee`（同步 dev→oss；**推送只走 `tools/gitee_push.py`**，判据＝远端 sha == 本地 HEAD）→ 打 tag → 建 **Gitee 发行版**（★GitHub 自 2026-10-16 停止更新）
（正文写清"修了什么 / 已知限制 / 怎么反馈"）；对外反馈按 **版本号 + `data/logs/server_stdout.log` 尾部**定位。
⚠️ **`__version__` 升版与 `CHANGELOG` 条目必须同一笔提交** —— 守卫
`TestVersionSingleSource::test_changelog_mentions_current_version` 会拦（2026-10-15 实测：我先升版本、

不再一小步一问、不再"要不要我做 X"；**并且在工作过程中持续更新本模型**（本节即其产物）。
