# 使用流程 · 从零到跑通（面向使用平台的人）

> 状态：**现行**（2026-11-01）。**这份是"用户手册"，权威口径在 `V116 §8.2`（15 步）与 `§8.0`（名单口径）。**
> 读法：想先知道全貌看 §0；照着做从 §1 开始往下走；撞到报错直接跳 §7 的撞墙清单。
> 全文**没有本机路径、没有真实 harness 名**（示例一律「示例Harness-A」）。

---

## 0. 五分钟全貌

```
【平台外】你自己跟网页版 AI 把需求和资料谈清楚、整理好      ← 平台不参与、不记录
   ↓
【建间】大厅 → 建工作间（给它一个目录、一个短名、粘上方向）    ← 平台落目录
   ↓
【选组长】平台只列"够格当组长"的（能写文件 + 有协议或桥）
   ↓
【拉组长】复制「组长对接单」→ 粘给你那边的 AI → 回来打勾/等它真发请求
   ↓
【深谈建模】你和组长聊，它把建模写进目录                     ← 平台一句都不插手
   ↓
【建资料库】你自己新建一个文件夹（**可以在工作区之外**）→ 平台里填「资料库指向」
   ↓
【开岗】组长回一份**名单回执**（岗位 / 该用什么 harness / 几个人）
   ↓
【拉人】复制「成员对接单」（每份路径都是**该员工自己的工位**）→ 逐个粘给 AI
   ↓
【派活】组长派活：任务文件 + 通知 + 登记，三样都真写进盘才算派出
   ↓
【干活】员工往自己的 `产物/` 里写东西
   ↓
【验收】你看证据 → 通过 / 返工 / 拒收（**通过要够格的证据**）
   ↓
【归档】平台记账、吊销凭据、写日结
```

**一条贯穿全程的铁律**：**脚本做了 ≠ 做成了**。凡是"可能做了但没自证"的，平台一律标**未核实**，
界面上不会把它显示成"成功"。反过来，平台自己**亲眼看到**的（真扫到文件、真收到回话），
账上会标成"平台验的"——这两种在界面上**长得不一样**（见 §6）。

## 1. 开始之前

### 1.1 你要准备什么

| 准备项 | 必须? | 没准备会怎样 |
|---|---|---|
| 一个 Python 环境（3.10+）与依赖 | **必须** | 起不来，会直接报缺哪个包 |
| 至少一个**已注册的 harness**（你的 AI 工具壳） | 必须（要拉人时） | 选组长时列表是空的，并提示先去大厅注册 |
| 一个**工作区目录**（空文件夹） | 必须 | 建工作间时要求路径 |
| 一个**资料库目录**（可以和工作区不同） | 建议 | 不填就用工作区里的默认资料库 |
| 各 AI 工具自己的接入配置（桥脚本 / 协议地址） | 看你的工具 | 拉人那步会告诉你**缺哪个字段**，不会瞎填 |

### 1.2 起服务

```bash
# 在仓库根目录（含 agent_community 包的父目录）跑
python -m agent_community.cli start          # 起服务 + 桌面窗口
python -m agent_community.cli start --no-gui # 只要后端
```

- 端口与数据目录都能改：`AC_PORT=<端口>`、`AC_DATA_DIR=<目录>`（**换机器不用改代码**）；
- 想让它在挂了以后自己起来：`python tools/watchdog.py --daemon`；查活没活：`python tools/watchdog.py --check`。

### 1.3 打开界面

| 页面 | 干什么 |
|---|---|
| `/` 大厅 | 看有哪些工作间 / 任务 / 员工；从这里进工作间 |
| `/v5.html` | **v5 控制台**：一屏走完下面这 15 步（含验收证据卡、名单表、派活） |
| `/docking.html` | 对接中心：注册 harness、架桥、看接入状态 |

## 2. 第一段：立项与选帅（第 0–5 步）

### 第 0 步 · 你在平台外面先把事想清楚（**别跳过**）

平台**不参与**也不会记录这一步。你手里得有：需求、背景、约束、你整理的资料。
理由：平台自己**没有 AI**，它不替你想方向；它是"把关 + 记账 + 交接"的那一层。

### 第 1 步 · 建工作间

大厅 → 建工作间，填：短名（必填）、工作区目录、方向（长文粘贴 + 下拉至少选一个）。

**做完怎么算数**：那个目录**真出现在磁盘上**（平台会 stat，不是只存个字符串）。
**没做对会看到**：目录建不出来会直接报错并给出原因，不会假装成功。

### 第 2 步 · 选组长

平台只列**够格**的候选：该 harness 得能**写文件**（`fs_write`），并且有**协议或桥**（能被叫醒）。
列表是**按名字排序，不是推荐**——平台不替你挑人。

**没做对会看到**：你硬选一个不够格的，会拿到 `409 NOT_LEAD_ELIGIBLE` 并说明它缺什么。

### 第 3 步 · 复制「组长对接单」

点一下就生成。里面**桥参数已经填好真实路径**（「## 桥参数（平台已填好路径，别手改）」那一段），
你**一键复制**粘给你那边的 AI 即可。

**做完怎么算数**：单子里的路径是**真实路径**，没有 `{{占位符}}`；缺什么会列进 `bridge_missing`，
平台不会瞎填一个值糊过去。

### 第 4 步 · 把对接单粘给组长（平台外）

你去那个 AI 的窗口里粘。这一步平台看不见。

### 第 5 步 · 回来「接组长」

按你那边的情况记证据。有两种方式，**平台分得清是谁验的**：

- **A 档（协议型，平台自己验）**：对接单第 6b 节里有一段**一次性回话口令**（`XXXX-XXXX` 这种）。
  那个 agent 必须用**该工位的凭据** + 这段口令打一次 `POST /api/workshop/{id}/members/{seq}/handshake`。
  答对了 ⇒ 平台**自己**把"接上了"记上，并盖上时间戳。
  · 口令错一个字符 ⇒ `HANDSHAKE_MISMATCH`；用过的 ⇒ `HANDSHAKE_ALREADY_USED`；
  · 拿平台主 token 去打 ⇒ `401 TOKEN_BAD`（必须是工位那份凭据）；
  · 重拼一次对接单 ⇒ 旧口令**当场作废**。
- **C 档（视觉型，你打勾）**：粘贴了 / 按了回车 / 看到它改名了，三项打勾 + 写一句"覆盖到哪一段"。

**做完怎么算数**：状态变成 `active`（才允许派活）。证据不齐就停在 `acked`，并告诉你还缺哪项。

## 3. 第二段：深谈建模与资料库（第 6–9 步）

### 第 6 步 · 你和组长聊，它把建模写进目录

平台**零写库**：它不参与你们的讨论，只认结果——`_lead/建模.md` 有没有真出现在工作区里。

### 第 7 步 · 你自己新建一个文件夹当「资料库」

**这个文件夹可以在工作区之外**——因为资料库里装的是"人写的资产"（方案、素材、参考资料），
不是一次性的产物。

### 第 8 步 · 组长把「项目建模 + 分工明细」写进资料库

**做完怎么算数**：资料库里真有两个文件（平台能列出它们）。

### 第 9 步 · 在控制台填「资料库指向」

把那个文件夹的路径填进去。

**没做对会看到**：相对路径会被拒（`PATH_NOT_ABSOLUTE`）；目录不存在**如实告诉你**，
**平台不会替你建**（建了就成了"看起来配好了"）。

---

## 4. 第三段：开岗与拉人（第 10–12 步）

### 第 10 步 · 组长交回「名单回执」

回执里写：岗位、该用什么 harness、人数。平台据此**真的建出对应数量的工位**（状态"待接"）。
比如写「人数: 5」就是**建 5 个工位**，不是只记一个数字。

**做完怎么算数**：回执通过（坏行会整单拒，并告诉你哪一行坏了）。

### 第 11 步 · 复制「成员对接单」（一人一份）

每份单子里的路径都是**该员工自己的工位目录**（不是组长的、不是别人的）。
同样自带「桥参数」段，一键复制即可。

### 第 12 步 · 逐个粘给员工

跟第 5 步一样记证据。这里有两条你会用得上的：

**① 名单和实到对不上怎么办？——平台不会拦你，但会说人话**

- 名单 5 人、只拉进 3 人：**照样能开工**（一个 agent 抽风不该把整间活儿停掉）；
- 界面会显示一句：`名单 5 人，已接上 3 人，还差 2 个（前端组#4、前端组#5）—— 空工位不能派活`；
- 你给**空工位**派活时才拦（`409 GATE_G5`，四要素说清缺谁 / 缺什么 / 去哪补 / 照做的一句话）。

**② 拉进来的人换了名字 / 你怕记错人？——平台核不出来，但你可以让它比**

- 平台看不到你那边应用里的会话标题，它只知道自己给工位生成的身份名；
- 所以接人时有个**可选**框「它现在实际叫什么」：填了就与身份名比，不一致**只提醒不拦**
  （「名单上叫 X，你说它叫 Y —— 是同一个换了名，还是换了另一个？」）；
- 不填就**没有**核对结果，界面会老实标「这个名字是你给的，平台没核过它真实叫什么」。

## 5. 第四段：派活、干活、验收（第 13–15 步）

### 第 13 步 · 组长派活

平台做三件事：写任务文件、往 `_notice` 追加、把这条任务登记进 `manifest.active_tasks`。
**三样缺一不算派出**，界面上会逐格显示卡在哪一步（`steps` + `stuck_at` + `why` + `next`）。

- **人工贴**（`manual`）是**正常终态**，不是失败：界面会显示"去它的窗口说一句「看下 组/任务/T-001.md」"。
- 给**没接上**的工位派活：`409 GATE_G5`，四要素齐全。

### 第 14 步 · 员工干活，产物落到自己的 `产物/`

**做完怎么算数**：平台**真扫盘**（目录 diff，L0）。它自报"写完了"但目录是空的 ⇒ 清单就是空，
并明说"别把它当'它说做完了'"。

> ⚠️ 一个容易看反的地方：产物清单里的「新增」是**相对上一次扫描**的增量。
> 你要是先点过「扫描产物」再来看，新增可能是 0——**不代表没产物**。
> 判"有没有交东西"要看**盘上现存数**（`files_now` / `总文件数`）。

### 第 15 步 · 验收 → 归档

**验收会给你一张「证据四步表」**（不是进度条）：

```
① 派活记录     ② 产物在盘上      ③ 回执留痕      ④ 人拍板
```

- **第 1、4 步是硬的**：没有派活记录就无从验收；必须有人给结论（通过 / 返工 / 拒收）；
- **第 2、3 步是"可用的证据档"**，**不是四步都要打勾**——有一档够格就能过；
- 卡住时会告诉你**卡在哪一步、为什么、该谁去补、补完点哪儿**。

**通过需要够格的证据**：

| 档 | 什么情况能用 | 谁验的 |
|---|---|---|
| `L0` | 盘上真扫到产物 | **平台** |
| `L1` | 「它库里有」——**必须写清凭据**（哪个库/哪个会话/谁核的/用什么工具核的） | 你给的凭据，**平台没去查** |
| `L2` | 平台有留痕（回执等） | 平台 |
| `L3` | 它自己说做完了 | **永不采信**（直接用会被拒） |
| `L4` | 你亲眼看过 | 你 |

- 没写凭据的 `L1` 会被拒（`L1_NEEDS_PROOF`），并按 `L4`（人眼确认）算；
- **产物目录真扫到 0 个文件时只允许 `L4`**——`L0/L1/L2` 都不够。

**归档**：`close` 会把工作人员间置为 closed 并**吊销全部凭据**（关了就收不回来），
工作区目录**原样保留**（归档不搬文件）。

## 6. 三档证据：谁验的，看哪里

| 档 | 平台怎么知道"接上了" | 账上标 |
|---|---|---|
| **A 协议型** | 它答对了平台写在对接单里的一次性口令 | `platform-observed`（**平台验的**） |
| **B 桥型** | 平台自己往邮箱写一条测试消息，亲眼看它被桥取走（文件进了 `delivered/`） | `platform-observed`（**平台验的**） |
| **C 视觉型** | 你打勾（粘贴 / 回车 / 改名） | `user-check`（**你打的勾**） |

界面上这两类**必须长得不一样**：
「平台验的」带时间戳、点开能看凭据；「你打的勾」就老实写是你打的。
**看时间戳分不出来**——打勾也会留时间戳，区别只在"谁验的"。

## 7. 撞墙清单：你会看到什么，怎么处理

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| `410 FREECHAT_RETIRED` | 你在用**已退役**的自由讨论入口 | 讨论改走结构化入口 `/ailp`；一条条自由发言不再收 |
| `410 AI_SELECT_RETIRED` | 你在用**已退役**的"让平台 AI 选人" | 名单由**组长回执**给出；手动加人写进 v5 名单（标 `manual`） |
| `409 GATE_G0` | 工作区的清单（manifest）不合格 | 看返回里的四要素，先修 manifest |
| `409 GATE_G4` | 一个 `active` 成员都没有 | 先把至少一个人接上（A 验口令 / B 取件 / C 打勾） |
| `409 GATE_G5` | 你在给**没接上**的工位派活 | 先把那个工位接上 |
| `409 NOT_LEAD_ELIGIBLE` | 选的组长不够格 | 换一个能写文件 + 有协议/桥的 |
| `400 L1_NEEDS_PROOF` | 验收用了 `L1` 但没给凭据 | 补 `evidence_ref`，或直接改 `L4` |
| `400 ARTIFACTS_EMPTY` | 产物目录真扫是 0 个文件 | 让它真写出产物；或你用 `L4` 人眼确认 |
| `400 HANDSHAKE_MISMATCH` / `HANDSHAKE_ALREADY_USED` | 口令不对 / 用过了 | 照对接单第 6b 节原样复制；或用过的就重拼一张单子 |
| `401 TOKEN_BAD` / `403 TOKEN_SCOPE` | 凭据不对 / 不是这个工位的 | 用**该工位**的凭据；别拿平台主 token 或别人的 |
| `PATH_NOT_ABSOLUTE` | 资料库填了相对路径 | 填绝对路径 |

**一条通用规则**：平台拦你的时候**一定给四要素**——谁 / 缺什么 / 去哪补 / 照做的一句话。
看到只有"失败了"三个字，那就是 bug，请报给我们。

---

## 8. 一句话总结

**平台不替你想、不替你判、不替你写；它只做三件事：把路径和参数填对、把门守住、把"谁验的"记清楚。**
你要决定的是"做不做、谁来、算不算"；平台负责让这些决定**有据可查、错了能看见**。
