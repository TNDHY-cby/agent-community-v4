# 开发任务总表（**唯一清单**）

> 口径：**一项任务一条**，每条都写清「开发/修什么 + 在项目设计模型里的位置 + 判据 + 估算」。
> **新任务一律往这里加**，不再散落在对话里；改完状态就地更新（`待做` → `在做` → `已交付`）。
> 交付判据：**判据工具真跑全过 + 已提交**；"我觉得做完了"不算。
> 发版按批次攒（4.47、4.48…），不为一处小改发版。
>
> 位置索引的读法：`模型表第 N 条` 指 [`项目完整模型.md`](项目完整模型.md) 主表第 N 行；
> `Vxxx §节` 指 [`design-docs/Vxxx_…md`](.) 里的具体章节；`model/xx` 指 [`model/`](model) 分册。
