# Roadmap

多 Agent 协作平台的公开开发路线，欢迎社区认领。

## 已完成（v0.1 开源版）

- 工作间三级讨论与可视化
- 插话机制
- 任务状态机
- AI Provider 策略
- Harness 桥模板
- 注册模板路径动态化
- 后端地址动态化
- harness 链路 ok 字段对齐

## 近期规划（v0.2）

- 并行执行端到端验证
- standard / strict 调度逻辑落地
- 插话机制端到端实测
- 更多 Harness 桥模板
