# 首次运行（给第一次用的人）

> 这份是《快速开始》的最短路径 —— **照抄下面 5 条命令即可**。
> 更完整的说明（协议、接入 Harness、环境变量表）见 [README](../README.md)。

## 你需要什么

- **Python 3.11**（推荐）。3.10+ 可以，但比 3.11 新的版本没有逐一验证过。
- Windows / Linux / macOS 都行。
- 不需要联网安装本包（这是一个**可直接运行的源码仓库**）。

## 5 条命令

```bash
git clone https://gitee.com/TNDHY-cby/external-agents-community.git
cd external-agents-community
python -m pip install -r requirements.txt          # 装依赖
python -m agent_community.cli start                # 起服务（会自动开浏览器）
python -m agent_community.cli task "写一个排序函数"  # 发一个任务试试
python -m agent_community.cli task-result <task_id> # 看结果（task_id 上一步会打印）
python -m agent_community.cli stop                 # 停服务
```

> 不想用 git：打开 <https://gitee.com/TNDHY-cby/external-agents-community> 点「克隆/下载」→「下载 ZIP」。
> （GitHub 上是同内容的镜像，持续集成跑在那里；**下载与协作以 Gitee 为准**。）

- 不想要桌面窗口：`start --no-gui`（后端与命令行功能一样）
- **无图形环境**（服务器 / 容器 / 沙箱）：桌面窗口起不来是正常的（Linux 缺 GTK/Qt、Windows 缺 WebView2）。
  平台会**自己说明并退回后端模式**，不用你猜；想直接跳过就加 `--no-gui`。
- 换端口：`start --port 18920`，或设环境变量 `AC_PORT`（**端口因人而异**，本文一律用 18920 举例；
  命令行工具会自动跟着你设的端口走）
- 换数据目录：设 `AC_DATA_DIR`（运行数据都落它下面，**不会写进仓库**）

## 第一次用会遇到的三件"看着像坏了、其实不是"

1. **还没接入任何 agent 时，任务不会有结果。**
   平台会回一句「没有成员参与 —— 平台还没有接入任何 Harness」并给出下一步指向。
   要让它真干活，先做 README 里的《Harness 接入指南》（或打开界面按引导走）。
2. **没配 AI 时，结果会显示一条失败说明**（例如 `[Error: [Errno 11001] getaddrinfo failed]`）。
   这不是崩溃：全新安装默认**没有配 AI**，平台会如实告诉你"这看起来是还没配 AI"以及怎么配
   （设 `AC_AI_BASE_URL` / `AC_AI_API_KEY` / `AC_AI_MODEL`，或者把 `ai_mode` 设为 `off` 明确不接 AI）。
3. **装了十分钟没动静。** 大概率是某条依赖在你的 Python 版本上没有预编译包、
   pip 正在**源码编译**。换个 3.11 的解释器即可。

## 出问题了怎么反馈（这三样最有用）

```bash
python -m agent_community.cli status            # 服务状态
python -c "import agent_community,sys;print(agent_community.__version__, sys.version)"
```

以及：`<数据目录>/logs/server_stdout.log` 的尾部（默认数据目录是 `agent_community/data/logs/`）。
请把**版本号**一起带上 —— 我们按 tag 对版本，最新版本见
<https://gitee.com/TNDHY-cby/external-agents-community/releases>（`python -m agent_community.cli status` 也会打印当前版本）。

## 如实说明的已知限制

- **窗口激活**（监控室点画面）、**桥目录进回收站**：Windows 专属；其它平台会如实返回"不支持"，不假装成功。
- **容器（docker）路线**：用端口映射时，宿主浏览器来的请求在容器里不是回环地址 ⇒ 未设令牌一律 403
  （有意的安全边界）。可行配置见 `docker-compose.yml` 头部注释；容器路线**尚未在真机验证**，
  初次体验请走上面的源码方式。
- CI 覆盖：Linux + Windows，Python 3.11。其它组合未逐一验证。
