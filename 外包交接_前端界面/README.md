## 4. 你怎么本地跑起来 + 自检（三条命令）

```bash
# ① 起一个隔离实例（换端口 + 换数据目录，别碰任何人的真实数据）
#    Windows PowerShell：
$env:AC_PORT="18925"; $env:AC_DATA_DIR="$env:TEMP\acfront"
python -m agent_community.platform.server --port 18925
#    浏览器打开 http://127.0.0.1:18925/docking.html  （总控）
#    单间入口：/docking.html?ws=<某个工作间id>

# ② 预检（对着设计稿逐条给结论；全 PASS 才算做完）
python 外包交接_前端界面/check_frontend_spec.py

# ③ 机器判不了的手感项：照 `验收清单.md` 的「人工走查」自己走一遍
```

> 依赖装不上也别卡住：界面是纯静态文件（`docking.html` / `docking.js` 直接改、直接看），
> 后端起不起来只影响"能不能连真数据"；预检 ② 只读文件，**不需要起服务**。

## 5. 判据（一句话）

> **换一个目录 + 换一个端口 + 换一个数据目录，不改一行代码就能走通。**

做不到就**如实说做不到**（不要"看起来成功"）。另外三条最常见的打回原因：
① 把对接中心写成"说明书"（大段教程文字）；② 出现 `/discuss`（讨论/工作一律留工作间）；
③ 写请求绕过白名单通道。

---

## 6. 有疑问怎么办

- **要新端点 / 新字段**：写清"界面要办什么事、缺什么数据"，我们加，不动你的代码。
- **设计稿里有歧义**：以 `FE-26` 的**一句话定位 + 硬约束**为准，其余展现方式你定 —— 我们要的是"一眼就会的操作台"。
- 交付前跑 ②③ 两遍；交付时附上填好的 `交付说明模板.md`。
