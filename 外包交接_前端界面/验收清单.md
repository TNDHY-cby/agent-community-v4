## 2. 人工走查（机器判不了，必须人看）

| 勾 | 走查项 | 怎么做 / 看什么 |
|---|---|---|
| ☐ | **M1 一眼就会** | 打开 `/docking.html`，**5 秒内**能否说出"这里能办哪几件事"（第一屏不点任何东西） |
| ☐ | **M2 办不成要说清** | 故意给一个错关键词 → 点「让平台去找」：找到几个？为什么？下一步提示了吗？<br>投给一个**不存在的窗口**：必须**当场说失败 + 原因 + 下一步**，不许显示"完成" |
| ☐ | **M3 空状态给动作** | 全新实例（没有任何 harness）打开页面：空白处要给"接下来点什么"，**不要给一段解释** |
| ☐ | **M4 单间不越权** | 用 `?ws=<某个间>` 打开：看不到工作间选择器、看不到注册入口 |
| ☐ | **M5 三态真的分得开** | 找一个 `verified` 不为真的成员：界面**必须**写「⚠ 待人工/未核实」；只有真的自证过才出现「✓」 |
| ☐ | **M6 文案是人话** | 不出现英文报错直出、不出现 `undefined`/`[object Object]`、不出现内部字段名（`access_tier` 这类已退休字段**一律不许出现**） |
| ☐ | **M7 手机/窄屏不炸** | 窗口拉窄到 ~400px，主要操作仍能点到（不要求做移动端，只要不崩） |
